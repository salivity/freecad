Set FreeCAD Sketch Origin to Specific Coordinates

In FreeCAD, anchoring a sketch origin to specific 3D coordinates is accomplished by defining the sketch’s placement in the 3D space rather than moving the origin point inside the sketch editor itself. Because a sketch’s internal origin is permanently fixed at (0,0) on its local 2D plane, positioning that origin requires either editing the sketch’s Placement properties, adjusting its Attachment Offset, or binding the sketch to a parametric Datum Point.

Method 1: Using the Placement Property

This is the fastest method to position an unattached (floating) sketch at specific global coordinates.

  1. Close the Sketcher workbench if you currently have the sketch open.
  2. In the Tree view, select your sketch.
  3. Switch to the Data tab in the Property view (located in the lower-left panel by default).
  4. Locate the Placement property and click the small arrow to expand it.
  5. Expand the Position sub-property.
  6. Enter your desired values into the x, y, and z fields. The sketch origin will immediately shift to these exact 3D coordinates.

Alternatively, you can click the ellipsis button (...) next to the Placement row to open the Placement task panel, where you can define both position coordinates and axial rotations simultaneously.

Method 2: Using Attachment Offset (Part Design)

If your sketch is created inside a Part Design Body and attached to a standard plane (such as the XY-Plane), modifying the direct Placement property might be overridden by the attachment engine. Instead, use the Attachment Offset.

  1. Select the sketch in the Tree view.
  2. In the Data tab, locate Attachment Offset.
  3. Expand Attachment Offset, then expand Position.
  4. Enter the required X, Y, and Z coordinate offsets.
  5. If necessary, adjust the rotation angles under the same menu to orient the sketch plane properly.

Method 3: Anchoring to a Datum Point (Parametric Approach)

For complex parametric models, anchoring a sketch to a dedicated Datum Point ensures that changes to model dimensions propagate cleanly.

  1. Ensure you are in the Part Design workbench.
  2. Click the Create a datum point tool in the toolbar.
  3. In the Combo View, enter the specific X, Y, and Z coordinates for the datum point in the attachment/offset parameters, then click OK.
  4. Select the newly created Datum Point in the Tree view.
  5. Click Create a new sketch. FreeCAD will automatically anchor the sketch origin to the coordinate position of the Datum Point.

Anchoring Internal Geometry to the Origin

If your sketch origin is already at the correct 3D coordinates and you want to anchor drawing elements directly to it:

  1. Double-click the sketch to open the Sketcher.
  2. Select the point or vertex of your drawn geometry.
  3. Select the red dot at the center of the grid (the sketch origin).
  4. Click the Coincident Constraint tool (or press the C key). This locks your geometry directly to the coordinate-anchored origin.
