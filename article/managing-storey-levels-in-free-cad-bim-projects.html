Managing Storey Levels in FreeCAD BIM Projects

Managing storey levels in a FreeCAD BIM project involves establishing a hierarchical spatial structure, defining floor elevations, and assigning architectural elements to their respective levels. By utilizing the Level and Building tools within the BIM workbench, you can control the vertical positioning of elements, maintain accurate floor-to-floor heights, and streamline documentation and export processes like IFC generation.

Activating the BIM Workbench

To manage storeys, switch to the BIM Workbench from the workbench drop-down menu in the top toolbar. This interface provides dedicated spatial container tools required for architectural design.

Creating the Project Hierarchy

  1. Click the Project button on the BIM toolbar to create a root project structure.
  2. Select the project container and click the Building tool to add a building object.
  3. With the building selected, click the Level (or Storey) tool to insert a new floor level into your hierarchy. Repeat this step for each floor required in your design (e.g., Ground Floor, First Floor, Roof).

Adjusting Storey Heights and Elevations

Each level acts as a reference plane for elements placed within it. You control these elevations through the Property View (Data tab):

  • Placement: Expand the Placement property and adjust the Position.Z coordinate to set the absolute elevation of the floor above ground zero.
  • Height: Set the Height property to define the vertical clearance or floor-to-floor dimension for that specific storey. This value is used automatically when generating spaces or default wall heights.

Assigning Objects to a Storey

To maintain an organized model and ensure valid IFC exports, geometry must reside inside the appropriate level:

  • Drag and Drop: In the Tree View, drag existing walls, slabs, windows, or structural elements directly onto the target Level container.
  • Active Level: Double-click a Level in the Tree View to make it active. Any new architectural elements created thereafter will automatically be placed inside that level at its defined Z-elevation.

Aligning the Working Plane to Storeys

To model accurately on a specific floor:

  1. Select the target level in the Tree View.
  2. Press the Working Plane button in the BIM status bar (or use the shortcut W, P) and select Top to snap the drafting grid directly to the elevation of that storey.
  3. Draw walls, structural beams, or slabs; they will automatically align with the level's base elevation.
