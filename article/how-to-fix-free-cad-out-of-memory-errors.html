How to Fix FreeCAD Out of Memory Errors

FreeCAD can consume excessive system RAM when processing complex parametric features, dense meshes, or long modeling histories, which often results in severe lag or abrupt crashes. This troubleshooting guide provides direct, actionable methods to resolve out-of-memory errors in FreeCAD, covering internal cache management, viewport optimization, geometry simplification, and operating system adjustments.

1. Increase Virtual Memory (Swap or Pagefile)

If physical RAM is exhausted, your operating system relies on virtual memory to prevent immediate application termination.

  • Windows: Open System Properties > Advanced > Performance Settings > Advanced tab. Under Virtual memory, click Change, uncheck automatic management, and set a custom size with a maximum of at least 1.5 to 2 times your physical RAM.
  • Linux: Increase your swap partition or create a dynamic swap file using fallocate or dd, then activate it using swapon.

2. Reduce the Undo/Redo Cache

FreeCAD stores prior document states in RAM to allow undo operations. On complex designs, this cache quickly consumes gigabytes of memory.

  1. Go to Edit > Preferences > General.
  2. Select the Document tab.
  3. Locate Maximum Undo/Redo steps and lower the value (setting it between 5 and 10 significantly reduces memory overhead).
  4. Uncheck Save thumbnail into project file to save additional overhead during save operations.

3. Adjust Viewport Tessellation and Deflection

High-precision visual rendering generates millions of polygons in the background, overwhelming your memory.

  1. Go to Edit > Preferences > Part Design (or Part).
  2. Navigate to the Shape view tab.
  3. Increase the Maximum deviation (chordal deflection) value (e.g., from 0.05% to 0.5% or higher). A higher number reduces the visual polygon count on curved surfaces without altering the true CAD geometry.
  4. Set Angular deflection to a higher value to further decrease facet generation.

4. Break Large Assemblies into Smaller Sub-Assemblies

Monolithic files containing hundreds of parametric operations will eventually exhaust memory.

  • Divide large projects into modular parts and reference them using workbenches like Assembly3 or Assembly4.
  • Export completed static components to intermediate formats (such as STEP) and re-import them as non-parametric shapes to eliminate the computational graph and memory history of those individual bodies.

5. Simplify Meshes and Clean Up Geometry

Imported STL, OBJ, or STEP files often contain redundant vertices and unoptimized surfaces.

  • In the Mesh Workbench, select dense meshes and run Meshes > Decimation to reduce triangle count.
  • In the Part Workbench, use Part > Defeaturing or Check geometry to locate and fix broken faces, self-intersections, and redundant edges that force the Open CASCADE Technology (OCCT) kernel into computational loops.

6. Purge Unused Data and Manage Memory Leaks

FreeCAD does not always immediately release memory back to the operating system after large operations or closing tabs.

  • Save your project, close FreeCAD completely, and reopen it to flush process memory.
  • Avoid keeping multiple large tabs open simultaneously.
  • Disable third-party add-ons or workbenches you do not actively use via Tools > Addon manager, as background scripts can create memory leaks.

7. Run FreeCAD in Headless Mode for Heavy Computations

If you are performing massive automated tasks, meshing, or exports that crash the graphical interface:

  • Execute operations using FreeCAD's command-line interface (freecadcmd). Running without the graphical user interface (GUI) drastically reduces overall baseline memory usage.
