Draft Wire vs Sketcher Sketch in FreeCAD

In FreeCAD, both Draft wires and Sketcher sketches are fundamental 2D profiles used to generate 3D models, but they are built on completely different modeling paradigms. While a Draft wire is a lightweight, coordinate-based polyline designed for traditional CAD and architectural workflows, a Sketcher sketch is a fully parametric, constraint-driven system intended for precise mechanical design. Understanding their differences in editing methods, performance, and workflow integration is essential for choosing the right tool for your project.

Core Modeling Paradigms

The primary distinction lies in how geometry is defined and modified:

  • Draft Wire (Draft Workbench): Operates on traditional, direct-modeling principles similar to standard 2D drafting programs like AutoCAD. A Draft wire consists of connected line segments defined strictly by explicit point coordinates in 3D space. To modify a Draft wire, you directly move points, adjust global coordinates, or use transformation tools (move, rotate, scale).
  • Sketcher Sketch (Sketcher Workbench): Operates on parametric, constraint-based solving. Instead of fixed coordinates, geometry is defined by relationships—such as horizontal, vertical, tangent, parallel, and dimensional constraints. A built-in constraint solver recalculates the shape dynamically whenever a dimension or relationship is modified.

Constraints vs. Direct Snapping

Draft wires rely on the Draft snap system during creation. You place points by snapping to endpoints, grid intersections, or midpoints. Once placed, the geometry has no active relationship with the objects it was snapped to; it is static.

In contrast, Sketcher sketches track "Degrees of Freedom" (DoF). A user draws loose geometry and then applies constraints until the sketch is fully constrained (zero degrees of freedom). This dynamic nature means changing a single dimension automatically updates the entire profile without breaking its geometric intent.

Performance and Scale

  • Draft Wires: Highly performant with large, complex sets of 2D data. Because there is no solver continuously checking geometric relationships, Draft wires are ideal for processing imported DXF or DWG files, architectural floor plans, and large-scale site layouts.
  • Sketcher Sketches: Computationally demanding. The solver can slow down significantly if a single sketch contains hundreds of geometric elements and constraints. Best practice dictates keeping sketches simple and focused on individual features rather than entire floor plans.

Workbench Integration and Use Cases

  • Use Draft Wires when working with BIM and Arch Workbenches: Draft wires work seamlessly with architectural tools to build walls, structures, and 2D documentation layouts. They are also useful for quick, unconstrained 2D layouts and processing external 2D CAD files.
  • Use Sketcher Sketches when working with the PartDesign Workbench: Sketcher is the backbone of feature-based mechanical modeling. Sketches serve as the base profiles for operations like Pad (extrusion), Pocket, Revolution, and Loft.

Interoperability

FreeCAD allows conversion between both types. You can convert a Draft wire into a Sketcher sketch using the "Draft to Sketch" tool to apply parametric constraints to imported geometry. Conversely, a Sketcher sketch can be downgraded or converted into a Draft wire if you need to export simple 2D vectors or bypass the constraint solver for architectural layouts.
