Package Managers for Installing FreeCAD on Ubuntu

FreeCAD, the open-source parametric 3D modeler, can be installed on Ubuntu through several package managers depending on your preference for stability, ease of updates, or sandboxed environments. This guide outlines the primary package managers supporting FreeCAD on Ubuntu—including APT, Snap, Flatpak, and Conda—and explains how to use each to get the software running on your system.

1. APT (Advanced Package Tool)

APT is the default package manager on Ubuntu. You can install FreeCAD via standard distribution repositories or through the official FreeCAD Personal Package Archive (PPA).

  • Official Ubuntu Repositories: Provides a stable, system-native build, though it may not always be the newest release.

    sudo apt update
sudo apt install freecad

  • Official FreeCAD PPA: Maintained by the FreeCAD team to deliver newer stable versions or bleeding-edge development builds.

    • Stable PPA:

      sudo add-apt-repository ppa:freecad-maintainers/freecad-stable
sudo apt update
sudo apt install freecad

    • Daily/Development PPA:

      sudo add-apt-repository ppa:freecad-maintainers/freecad-daily
sudo apt update
sudo apt install freecad-daily

2. Snap

Snap is Canonical’s universal package management system, which comes pre-installed on modern Ubuntu releases. Snap packages run in a secure, sandboxed environment and bundle their own dependencies, ensuring you receive the latest stable releases directly.

To install the official FreeCAD Snap package:

sudo snap install freecad

To switch to the edge channel for testing development versions:

sudo snap install freecad --edge

3. Flatpak

Flatpak is another popular universal application management framework that distributes containerized desktop applications. The FreeCAD Flatpak is maintained on Flathub, providing a self-contained installation that does not interfere with system-level libraries.

If your system already has Flatpak and the Flathub repository configured, install FreeCAD using:

flatpak install flathub org.freecadweb.FreeCAD

To run the application:

flatpak run org.freecadweb.FreeCAD

4. Conda (via conda-forge)

Conda (or its faster alternative, Mamba) is a language-agnostic package and environment manager widely used in scientific computing and engineering. The conda-forge community maintains up-to-date FreeCAD builds, making this the preferred route if you integrate FreeCAD into custom Python workflows or require isolated development environments.

To install FreeCAD in an active Conda environment:

conda install -c conda-forge freecad

Or using Mamba:

mamba install -c conda-forge freecad
