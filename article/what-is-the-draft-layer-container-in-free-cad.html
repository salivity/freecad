What Is the Draft Layer Container in FreeCAD?

The Draft layer container in FreeCAD is a specialized organization tool primarily used within the Draft and BIM Workbenches to manage, group, and control the visual properties of 2D and 3D objects. This article explains the core functions of Draft layers, how they differ from standard FreeCAD groups, their role in external CAD interoperability, and how they streamline overall project navigation and presentation.

Primary Purposes of the Draft Layer Container

1. Centralized Visual Property Management

The primary function of a Draft layer is property inheritance. When you place objects into a layer, you can configure those objects to inherit common display settings directly from the parent layer container. These properties include:

  • Line Color: Overrides or defines the edge color of all contained wireframes and boundaries.
  • Line Width: Sets a uniform thickness for curves, lines, and edges.
  • Shape Color: Defines the fill or face color of 2D surfaces and 3D solids.
  • Transparency: Controls the opacity of all child objects uniformly.
  • Draw Style: Standardizes display modes, such as dashed lines or solid edges.

By altering a setting in the layer container, every object assigned to use the layer’s properties updates automatically, removing the need to edit objects individually.

2. Scene Organization and Visibility Control

As models grow complex, the tree view and the 3D viewport can become cluttered. A Draft layer container allows you to control the visibility of entire systems—such as dimensions, structural grids, electrical lines, or architectural walls—with a single toggle. Hiding a layer hides all associated geometry simultaneously, allowing you to focus on specific aspects of the design.

3. Interoperability with Traditional CAD Systems

Traditional 2D drafting programs (such as AutoCAD or LibreCAD) rely heavily on layers (typically stored within DXF or DWG formats). FreeCAD uses Draft layer containers to map directly to these conventional CAD layers:

  • Importing: Importing a DXF file creates Draft layers corresponding to the source document's layers, preserving organizational structure.
  • Exporting: Exporting a FreeCAD document containing Draft layers accurately maps the geometry back to standard DXF/DWG layers, ensuring seamless collaboration with non-FreeCAD users.

Draft Layers vs. Standard Groups

FreeCAD provides standard group folders (App::DocumentObjectGroup), but they differ significantly from Draft layers:

  • Standard Groups: Act purely as structural folders in the Tree view. They do not pass visual attributes (such as color or line weight) to their child objects.
  • Draft Layers: Function as active property controllers. In addition to organizing the tree, they modify rendering behavior, support print styling, and integrate with the Draft Workbench's active drawing tools.

Working with Draft Layers

  • Creating a Layer: Layers are created using the "Draft Layer" button in the Draft or BIM Workbench toolbar.
  • Assigning Objects: You can assign objects by dragging and dropping them into the layer container in the Tree view or by modifying the object’s Layer property in the Data tab.
  • Active Layer Status: Double-clicking a layer or selecting it as the "Active Layer" ensures that any new geometry created with Draft tools is automatically placed inside that container upon creation.
