Organize Multiple Operations in a FreeCAD Path Job

Managing multiple machining operations within a single FreeCAD Path (CAM) job allows you to streamline your CNC workflow, optimize tool changes, and export a single unified G-code file. This guide covers how to structure, sequence, and group various operations—such as profiling, pocketing, and drilling—within the FreeCAD Job tree, ensuring efficient cutting sequences and collision-free toolpaths.

1. Add Operations to the Same Job Container

All machining operations must reside under a single Job object in the Tree view.

  1. Create a new Job by selecting your model and clicking the Job icon in the Path/CAM workbench.
  2. Configure your stock dimensions, base geometry, and default coordinate systems.
  3. Add your distinct operations sequentially (e.g., Pocket Shape, Profile, Drilling) by selecting the required geometry on your model and clicking the corresponding operation tool from the toolbar.
  4. Each new operation automatically populates inside the Operations subgroup of that active Job.

2. Reorder Operations for Correct Machining Logic

The order in which operations appear in the tree determines the execution order in the generated G-code. Typically, roughing operations precede finishing, and clearing bulk material precedes drilling or fine profiling.

  • Drag-and-Drop: Expand the Operations folder in the Tree view. Click and drag an operation up or down within the list to change its execution priority.
  • Property View: Alternatively, select the Operations group and adjust the operation list in the Data tab under the Property View if manual reordering in the viewport is disabled.

3. Assign and Group Tool Controllers

Efficient multi-operation setups minimize manual tool changes.

  1. Add necessary tools to the Job via the Tool Controller section of the Job setup.
  2. Select an individual operation in the Tree view and open its Data tab.
  3. Change the Tool Controller property to assign the specific bit required for that operation.
  4. Sequence operations that share the same tool back-to-back in the Tree view. This prevents redundant tool change commands in the exported G-code.

4. Group Operations with Compounds

When you have a series of operations that should be treated as a single entity (such as a roughing pass followed immediately by a finishing pass across several identical features), use a Compound.

  1. Select multiple operations in the Tree view using Ctrl + Click.
  2. Click the Path Compound button on the toolbar.
  3. The selected operations are grouped under a single compound node, making it easier to enable, disable, or move the entire sequence at once.

5. Suppress or Toggle Operations

You do not need to delete an operation to omit it from a test run or specific export.

  • Select the operation in the Tree view.
  • In the Data tab, locate the Active property and toggle it from True to False (or press the Spacebar to toggle visibility/activation depending on your FreeCAD version).
  • Inactive operations are skipped during toolpath generation and G-code post-processing.

6. Verify and Simulate the Full Sequence

Before exporting the final G-code:

  1. Select the top-level Job in the Tree view.
  2. Click the CAM Simulator (CamSim) tool.
  3. Run the simulation to review the entire sequence of operations in order. Look for collisions, rapid moves through uncut stock, and unnecessary rapid travel between mismatched tool sequences.
  4. Once verified, click Post-Process with the Job selected to generate a single G-code file containing all organized operations.
