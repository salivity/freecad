Purpose of Shell Elements in FreeCAD FEM

Shell elements in FreeCAD's Finite Element Method (FEM) workbench are 2D elements used to model thin-walled structures efficiently without requiring full 3D solid meshes. By assigning a mathematical thickness to a 2D surface, shell elements capture both membrane (in-plane) and bending (out-of-plane) behaviors with a fraction of the computational power required by 3D solid elements. This article explains the primary purposes, technical advantages, and practical applications of using shell elements in FreeCAD FEM simulations.

Overcoming the Limits of 3D Solid Meshing

When analyzing thin-walled geometries—such as sheet metal, automotive body panels, or pressure vessels—using 3D solid elements (tetrahedrons or hexahedrons) creates severe meshing challenges. To accurately capture bending behavior through the thickness of a part, an engineer typically needs at least two to three solid elements across that thickness. In very thin parts, this requirement leads to millions of microscopic elements, causing extremely long solve times or system memory crashes. Shell elements eliminate this issue by meshing only the mid-surface of the geometry with 2D elements (triangles or quadrangles), drastically reducing node counts while retaining full structural accuracy.

Prevention of Element Locking

Solid elements with high aspect ratios—where length and width are much larger than thickness—suffer from numerical errors such as "shear locking." Shear locking causes elements to appear artificially stiff under bending loads, producing inaccurate stress and displacement results. Shell elements are mathematically formulated to decouple bending, shearing, and membrane actions, avoiding aspect-ratio stiffness errors and providing reliable stress predictions for thin components.

Incorporation of Rotational Degrees of Freedom

Standard 3D solid elements only have three translational degrees of freedom (DOFs) per node: displacement in the X, Y, and Z axes. Because shells represent thin plates, their formulation includes both three translational and up to three rotational degrees of freedom per node (six DOFs total). This allows FreeCAD’s underlying FEM solver (typically CalculiX) to accurately calculate edge moments, twisting, and rotational boundary conditions that cannot be modeled directly on a 2D mesh using pure solid formulations.

How FreeCAD Implements Shell Elements

In FreeCAD, shell elements are applied to surfaces rather than 3D volumes:

  1. Geometry Selection: The user selects a 2D surface representing the mid-plane of the component.
  2. Mesh Generation: A 2D surface mesh is created using either the Gmsh or Netgen integration.
  3. Shell Thickness Assignment: The user applies the "FEM element geometry shell" constraint, specifying the thickness value and offset (top, middle, or bottom surface alignment).
  4. Solver Execution: When exported to CalculiX, the solver processes these 2D elements with their associated thickness matrix to evaluate membrane stresses, bending moments, and shear forces.

Primary Applications

Shell elements in FreeCAD are best suited for:

  • Sheet metal brackets, enclosures, and stamped components
  • Thin-walled storage tanks, pipes, and pressure vessels
  • Aircraft skins and structural aerospace ribs
  • Structural steel sections like I-beams, C-channels, and hollow structural tubes
  • Composite laminates where layers can be modeled along a 2D reference plane
