Export FreeCAD TechDraw Sheet to PDF

This guide provides a quick and reliable walkthrough for exporting technical drawings created in FreeCAD's TechDraw workbench into a standard PDF format. Converting your TechDraw sheets to PDF ensures your technical layouts, dimensions, and annotations are locked into a universally accessible format suitable for manufacturing, archiving, or sharing with clients.

Method 1: Using the TechDraw Export Tool (Recommended)

The most direct way to export a drawing is using the dedicated TechDraw export function, which preserves exact vector quality and scale.

  1. Open your document in FreeCAD and ensure the TechDraw Workbench is active.
  2. In the Tree View (left-hand panel), select the specific Page object you want to export. Double-click it to make sure it is currently displayed in the main viewport.
  3. Click the Export Page as PDF icon on the TechDraw toolbar (represented by a document icon with a red PDF label). Alternatively, navigate to the top menu and select TechDraw > Export Page as PDF.
  4. In the file dialog box, choose the folder where you want to save the document.
  5. Enter a file name and click Save.

Method 2: Using the Main Menu Export

If the TechDraw toolbar is hidden, you can achieve the same result via the standard application menu.

  1. Select the drawing Page in the Tree View.
  2. Go to File > Export PDF... in the top navigation bar.
  3. Choose your destination directory, name the file, and confirm by clicking Save.

Method 3: Using Print to PDF

If you need custom print resolution, page margins, or color adjustments not handled automatically by direct export, use the print engine.

  1. Make sure your TechDraw sheet is open and in focus.
  2. Go to File > Print... or press Ctrl + P (Cmd + P on macOS).
  3. Select your system's Print to PDF driver (such as Microsoft Print to PDF on Windows, or the native PDF dropdown on macOS/Linux).
  4. Verify that the paper size matches your TechDraw sheet template (for example, A4, A3, or ANSI Letter).
  5. Click Print and specify the output file location.

Tips for Best Results

  • Update Views Before Exporting: Ensure all projection views, dimensions, and section cuts are up to date by clicking the Redraw Page button (TechDraw > Redraw Page) before exporting.
  • Line Weights and Colors: Verify your line width settings in Edit > Preferences > TechDraw > Dimensions / Colors prior to export so line weights render legibly in the final document.
