How to Run OpenFOAM CFD Simulations in FreeCAD

Setting up computational fluid dynamics (CFD) simulations using OpenFOAM directly within FreeCAD is accomplished via the CfdOF workbench. This workflow bridges FreeCAD's 3D parametric CAD modeling capabilities with OpenFOAM’s powerful numerical solver, handling fluid domain definition, meshing, boundary conditions, solver execution, and post-processing within a unified interface.

Step 1: Install Prerequisites and the CfdOF Workbench

  1. Install OpenFOAM: Install a compatible version of OpenFOAM (such as OpenFOAM v2012+ or OpenFOAM-dev) on your operating system. Windows users typically install OpenFOAM via Windows Subsystem for Linux (WSL) or Docker.
  2. Install ParaView: Install ParaView for data visualization and post-processing.
  3. Install CfdOF in FreeCAD:
    • Open FreeCAD.
    • Go to Tools > Addon Manager.
    • Locate CfdOF in the Workbenches tab and click Install.
    • Restart FreeCAD.

Step 2: Configure CfdOF Preferences

  1. In FreeCAD, switch to the CfdOF workbench from the workbench dropdown.
  2. Navigate to Edit > Preferences > CFD.
  3. Under the OpenFOAM tab, specify the installation path for your OpenFOAM installation (or set the execution mode to WSL/Docker if on Windows).
  4. Verify the executable paths for meshing utilities (such as cfMesh or snappyHexMesh) and ParaView.
  5. Click Apply and OK.

Step 3: Prepare the Fluid Domain Geometry

  1. Model your part or import an existing STEP/IGES file using the Part or Part Design workbench.
  2. Ensure you are modeling the fluid domain (the space the fluid occupies), not the solid vessel walls, unless performing conjugate heat transfer. If necessary, use boolean operations in the Part workbench to subtract solid objects from a surrounding enclosure box to create the internal or external flow volume.

Step 4: Create a CFD Analysis Container

  1. Select the fluid domain solid in the tree view.
  2. Click the CFD Analysis container button on the CfdOF toolbar. This creates an analysis folder containing the physics model, fluid properties, mesh, and boundary conditions.
  3. Double-click the PhysicsModel object in the tree:
    • Select the Time model (Steady or Transient).
    • Choose the Flow regime (Incompressible or Compressible).
    • Choose the Turbulence model (Laminar, RANS such as \(k\)-\(\omega\) SST, or LES).
    • Click OK.

Step 5: Assign Fluid Properties

  1. Double-click the FluidProperties object in the tree view.
  2. Select a predefined fluid (such as Air or Water) from the library, or specify custom kinematic viscosity (\(\nu\)) and density (\(\rho\)).
  3. Click OK.

Step 6: Define Boundary Conditions

For each flow boundary, create a boundary condition:

  1. Click the CFD Boundary Condition tool.
  2. Select the relevant face on your 3D model and click Add.
  3. Choose the boundary type:
    • Inlet: Define a uniform velocity (e.g., fixed value along an axis) or volumetric flow rate.
    • Outlet: Define a static pressure condition (typically zero gauge pressure).
    • Wall: Set no-slip, slip, or moving wall conditions, along with surface roughness if applicable.
  4. Click OK and repeat for all boundaries in the domain.

Step 7: Generate the Mesh

  1. Select the fluid geometry and click the CFD Mesh button.
  2. Select the meshing utility: cfMesh (recommended for beginners) or snappyHexMesh.
  3. Set the Base Element Size to define the overall mesh resolution.
  4. (Optional) Add local surface refinements or boundary layers (viscous layers) to accurately capture near-wall shear stresses (\(y^+\)).
  5. Click Write Mesh, then click Run Mesh. Inspect the output log to confirm clean mesh generation without non-orthogonal or inverted cells.

Step 8: Run the OpenFOAM Solver

  1. Double-click the CfdSolver object in the tree view.
  2. Review parallel processing options: set the number of CPU cores for parallel computation.
  3. Set simulation convergence criteria and iteration limits (e.g., number of time steps or steady-state iterations).
  4. Click Write Case to generate standard OpenFOAM directories (0/, constant/, system/).
  5. Click Run to launch the OpenFOAM solver (e.g., simpleFoam for steady incompressible flow).
  6. Monitor the residual plot directly inside FreeCAD to ensure the simulation converges.

Step 9: Post-Process Results

  1. Once the solver finishes, click the ParaView button within the solver dialog.
  2. In ParaView, click Apply in the Properties panel.
  3. Visualize velocity vectors, pressure contours, and streamlines across slices or internal clip planes to evaluate your fluid dynamics results.
