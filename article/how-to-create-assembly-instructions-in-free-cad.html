How to Create Assembly Instructions in FreeCAD

Documenting assembly instructions in FreeCAD involves breaking down a 3D model into logical sequential steps, creating exploded assembly states, and generating clean 2D technical drawings with part lists and callouts. This guide walks you through the entire workflow, from preparing your 3D model with dedicated workbenches to exporting a print-ready, step-by-step PDF instruction manual using the TechDraw workbench.

Step 1: Install Required Workbenches

While core FreeCAD handles 2D documentation natively, generating exploded views is easiest with community add-ons.

  1. Open FreeCAD and navigate to Tools > Addon manager.
  2. Locate and install the ExplodedAssembly workbench.
  3. Restart FreeCAD to ensure the workbench loads correctly.

Step 2: Organize the 3D Model into Sub-Assemblies

Before detailing the instructions, structure your model logically in the Tree View.

  1. Group related parts into folders or sub-assemblies (e.g., base frame, motor mount, fasteners).
  2. Ensure each component has a distinct and descriptive label (e.g., "M4x12_Bolt", "Base_Plate").
  3. Determine the real-world build order from the first component to the final fastener.

Step 3: Create Exploded Steps

Use the ExplodedAssembly workbench to generate the visual sequence.

  1. Switch to the ExplodedAssembly workbench from the workbench dropdown.
  2. Select the part or group of parts you want to move in the first disassembly step.
  3. Click the Create a bolt exploded track or Create a simple exploded track tool.
  4. Use the directional handles or input exact offset values to pull parts away along their assembly vector.
  5. Repeat this process in reverse order of assembly until all parts are placed in their disassembled positions.
  6. Use the animation/step controls in the ExplodedAssembly panel to verify each movement corresponds to an assembly stage.

Step 4: Create a Drawing Sheet in TechDraw

The TechDraw workbench converts your 3D views into formal 2D documentation.

  1. Switch to the TechDraw workbench.
  2. Click Insert 'Default Page' or Insert Page using Template to choose an appropriate sheet size (e.g., A4 or US Letter landscape).
  3. Return to the 3D view, orient the camera to a clear isometric angle showing the current assembly step, and select the objects for that step in the Tree view.
  4. Return to your TechDraw page and click Insert View. Adjust the Scale and Direction properties in the Data tab if necessary.
  5. Create additional pages for each subsequent step in the assembly process, inserting the corresponding exploded or partially assembled state on each page.

Step 5: Add Balloons, Callouts, and Hardware Lists

Make the drawings functional by identifying each component.

  1. Add Item Balloons: Select a component's edge or vertex in the TechDraw view and click Insert Balloon Annotation. Label each balloon with a step number or item index.
  2. Insert Directional Arrows: Use the Insert Cosmetic Line or annotation tools to draw trajectory lines showing the insertion path of pins, bolts, and interlocking components.
  3. Add Text Instructions: Use the Insert Annotation tool to place written instructions next to each view (e.g., "Secure using 4x M4 screws; torque to 2 Nm").
  4. Bill of Materials (BOM): Use the Insert Spreadsheet View tool to include a table listing part numbers, descriptions, and quantities required for that specific step.

Step 6: Export the Documentation

  1. Review each page in the TechDraw tree to verify alignment, scale, and readability.
  2. Select the pages you want to include in the manual.
  3. Go to File > Export PDF to generate a single, multi-page instruction document suitable for digital viewing or printing.
