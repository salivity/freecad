How to Create 2D Drawings in FreeCAD TechDraw

This guide explains how to convert a 3D CAD model into a standardized 2D engineering drawing using FreeCAD’s native TechDraw Workbench. You will learn the complete workflow, including selecting drawing templates, inserting primary and secondary orthographic projections, adding accurate dimensions, editing title blocks, and exporting the finished sheet to industry-standard formats like PDF and DXF.

1. Prepare Your Model and Switch Workbenches

Ensure your 3D model is fully designed and saved. In the FreeCAD interface, open the workbench dropdown menu in the top toolbar and switch from your current workbench (such as Part Design or Part) to the TechDraw Workbench.

2. Insert a Drawing Page Template

To start a drawing, you must create a blank sheet using a pre-formatted standard template.

  • In the toolbar, click Insert Page using Template (represented by an orange page with a folder icon).
  • A file dialog opens displaying the default FreeCAD templates directory.
  • Select an appropriate sheet size and standard (e.g., A4_Landscape_ISO.svg or A3_Landscape_ASME.svg) and click Open.
  • A new page tab will appear below the 3D viewport, and a Page object will be added to the Model Tree.

3. Insert Base Views and Orthographic Projections

To project your 3D geometry onto the 2D sheet, you can insert either a single view or an orthographic projection group.

Method A: Projection Group (Recommended)

  1. In the Model Tree, click to highlight the 3D body or part you want to project.
  2. Click the Insert Projection Group tool.
  3. In the Task panel on the left, choose the primary projection direction (e.g., Front).
  4. Check the boxes for the adjacent views you need, such as Top, Right, and Isometric.
  5. Adjust the scale settings (e.g., 1:1, 1:2) and click OK.

Method B: Single View

  1. Switch back to your 3D view tab and orient the camera to the angle you want.
  2. Select the body in the Model Tree.
  3. Switch to the drawing page tab and click Insert View.
  4. With the view selected in the tree, modify the Scale, Direction, and Rotation properties in the Data tab.

4. Add Dimensions and Annotations

Once your views are positioned on the sheet, you can dimension the geometry.

  • Linear Dimensions: Hold Ctrl and select two vertices, or click a single edge, then click the Insert Length Dimension, Horizontal Dimension, or Vertical Dimension button.
  • Radius and Diameter: Select a circular edge and click Insert Radius Dimension or Insert Diameter Dimension.
  • Angle Dimensions: Select two intersecting edges and click Insert Angle Dimension.
  • Text Labels: Click Insert Annotation to place arbitrary notes, revision data, or manufacturing callouts onto the sheet.

To reposition dimensions, click and drag the dimension text directly on the page.

5. Populate the Title Block

Most built-in templates have editable text fields in the title block.

  • Click the green text fields within the title block to edit them directly.
  • Alternatively, select the Template item under the Page object in the Model Tree, go to the Data tab, and edit the editable field properties directly in the list.

6. Toggle Element Frames and Export

  • Click the Turn View Frames On/Off button on the toolbar to hide the dashed boundary boxes and point markers around views and dimensions, ensuring a clean preview.
  • To generate your final documentation, select the Page object in the Model Tree.
  • Go to File > Export to save the drawing as a DXF or SVG, or click TechDraw > Export Page as PDF to generate a print-ready document.
