How to Fix Out of Date FreeCAD TechDraw Views

When 3D models are modified in FreeCAD, linked TechDraw pages do not always update automatically, resulting in out-of-date views indicated by orange clock icons, hatched patterns, or stale geometry. This guide covers how to quickly identify out-of-date views, force manual updates across individual elements or entire drawing sheets, adjust automatic update preferences, and troubleshoot stubborn views that fail to refresh.

Identifying Out-of-Date Views

TechDraw signals that a view is out of sync with its parent 3D geometry in two primary ways:

  • In the 3D/Page View: A diagonal cross-hatch pattern or an orange clock icon overlays the drawing view, signifying that the current projection no longer matches the underlying geometry.
  • In the Tree View: A small blue or orange refresh icon appears next to the TechDraw Page or the specific View object.

Forcing a Recompute

To update stale views manually, use any of the following methods depending on the scope of the changes:

  1. Global Recompute: Press F5 or Ctrl + R (Command + R on macOS), or click the blue Recompute icon in the main FreeCAD toolbar. This recalculates the entire document, updating both the 3D model features and the 2D TechDraw pages.
  2. Redraw TechDraw Page: Open the drawing sheet, switch to the TechDraw Workbench, and click the Redraw Page button (represented by a drawing page with circular refresh arrows) in the workbench toolbar.
  3. Manual View Recompute: If only one specific view is lagging, right-click the view object in the Tree View, select Mark to recompute, and then press F5.

Configuring Automatic Update Settings

FreeCAD allows you to control whether TechDraw sheets update automatically when 3D geometry changes, which helps reduce lag when working on complex assemblies.

  1. Navigate to Edit > Preferences > TechDraw > General.
  2. Look for the Update with 3D model setting:
    • Enabled: TechDraw automatically recalculates sheets when the 3D model changes (can slow down performance on complex designs).
    • Disabled: FreeCAD suspends view recalculations until you explicitly trigger an update, keeping the views in an out-of-date state intentionally during heavy modeling sessions.
  3. Check the individual view property: Select the view in the Tree View, go to the Data tab in the Property View, and ensure Keep Updated is set to True. If set to False, the view will never update during document recalculations.

Troubleshooting Views That Refuse to Update

If a view remains out of date or displays an error after recomputing:

  • Update Upstream Dependencies: Ensure the 3D body itself has no errors. An unresolved broken sketch or failed fillet earlier in the feature tree will prevent TechDraw from rendering the projection. Fix the 3D model errors first, then recompute the drawing.
  • Topological Naming Issues: If faces, edges, or vertices referenced by dimensions were deleted or heavily modified, the view may enter an error state. Delete broken dimensions or reattach them to the updated geometry.
  • Toggle Hidden Line Removal (HLR): In the view's Data properties, toggle the Hard Hidden or Smooth Visible settings off and on, then hit F5 to force the internal projection algorithm to redraw.
