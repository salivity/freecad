Embed Custom Metadata and Author Info in FreeCAD

Embedding custom metadata and author information into a FreeCAD project is essential for tracking revisions, maintaining intellectual property records, and streamlining collaboration. FreeCAD provides multiple methods to achieve this, including global user settings for automated author attribution, the native Document Properties interface for file-specific data, and Python scripting for creating custom, arbitrary metadata fields.

Setting Default Author Information Globally

To ensure that your name and licensing details are automatically attached to every new file you create, configure FreeCAD's global preferences:

  1. Open FreeCAD and navigate to Edit > Preferences.
  2. Select the General tab from the left sidebar, then click on the Document sub-tab.
  3. Locate the Authoring and License section.
  4. Fill in the Author name, Company, and default License fields.
  5. Click Apply and then OK.

Any new document created after this will automatically include these credentials in its internal metadata.

Editing Document Properties for Existing Files

For existing files, or to set project-specific details such as project titles and notes, use the Project Information panel:

  1. Open the target FreeCAD file (.FCStd).
  2. Go to the top menu and select File > Project information....
  3. In the dialog window that appears, fill out or modify the available fields:
    • Title: The formal name of the project or part.
    • Created by: The author's name.
    • Creation date: The timestamp for the file.
    • Last modified by: The user who last saved changes.
    • Company: The associated organization.
    • Comment: Notes, revision summaries, or descriptive metadata.
  4. Click OK and save your document (Ctrl+S or File > Save).

Alternatively, you can select the root document node at the very top of the Model tree view. In the Property view panel below the tree, scroll through the properties to find and edit the Author, Comment, Company, and License values directly.

Adding Custom Metadata via Python

If you need custom key-value pairs that are not provided by default (such as Part Number, Revision Code, or Client Name), you can inject custom dynamic properties using FreeCAD's Python console:

  1. Ensure the Python console is visible by going to View > Panels > Python console.
  2. Run the following commands to add a custom string property to the active document:
doc = FreeCAD.ActiveDocument
doc.addProperty("App::PropertyString", "PartNumber", "CustomMetadata", "The internal part numbering code")
doc.PartNumber = "PN-10492-REV-B"

In this command:

  • "App::PropertyString" specifies the data type.
  • "PartNumber" is the internal property name.
  • "CustomMetadata" is the group name that will appear in the Property editor panel.
  • The final string is a tooltip description.

Once executed, select the document root in the Model tree. You will see your new CustomMetadata group in the Property view panel, where you can modify the custom property directly through the graphical user interface. Save the file to preserve the custom data.
