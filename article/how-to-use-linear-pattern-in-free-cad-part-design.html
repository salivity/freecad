How to Use Linear Pattern in FreeCAD Part Design

This guide provides a straightforward walkthrough on using the Linear Pattern tool in FreeCAD's Part Design workbench to duplicate features along a straight path. By applying this tool to features such as holes, pockets, or pads, you can quickly create evenly spaced rows or two-dimensional grids without having to sketch and extrude each instance individually.

Step 1: Select the Feature to Pattern

  1. Ensure you are working in the Part Design workbench with an active Body.
  2. In the Model tree view or directly in the 3D viewport, click on the feature you wish to duplicate (e.g., a Pocket, Hole, or Pad).

Step 2: Activate the Linear Pattern Tool

  1. With the feature selected, click the Create a linear pattern icon on the Part Design toolbar. Alternatively, go to the top menu and select Part Design > Apply a pattern > Linear Pattern.
  2. The Task panel will open on the left side of the screen, displaying the pattern parameters, and FreeCAD will show a real-time preview of the patterned feature.

Step 3: Configure the Primary Direction

Under the first direction settings in the Task panel:

  • Direction: Choose the alignment axis for the pattern. You can pick standard options such as Normal sketch axis, Vertical sketch axis, or Horizontal sketch axis. To use an existing edge as a guide, choose Select feature / Select reference and click an edge in the 3D view.
  • Reverse direction: Check this box if the duplicated features are expanding in the opposite direction of what you require.
  • Length: Enter the total span across which the instances should be distributed.
  • Occurrences: Set the total number of instances to create, which includes the original base feature.

Step 4: Configure a Second Direction (Optional)

To create a rectangular grid pattern:

  1. Check the Direction 2 option in the Task panel.
  2. Select the secondary direction reference (typically an axis or edge perpendicular to the first direction).
  3. Set the Length and the number of Occurrences for this second axis.

Step 5: Finalize the Pattern

  1. Review the preview in the 3D viewport to ensure the duplicated features remain entirely on or within the solid geometry of the body.
  2. Click OK in the Task panel to generate the linear pattern. The new pattern will now appear in the tree view as a LinearPattern object underneath your active Body.
