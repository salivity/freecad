Custom Line Weights and Styles in FreeCAD TechDraw

This guide explains how to configure and apply custom line weights and line styles within the FreeCAD TechDraw workbench. You will learn how to modify global default settings, apply custom visual properties directly to specific drawing views and edges, and configure custom Line Groups using standard-compliant configuration files.

Setting Global Line Defaults

To define universal line widths and patterns across all new drawings:

  1. Open FreeCAD and navigate to Edit > Preferences.
  2. Select the TechDraw workbench icon from the left sidebar.
  3. Switch to the Lines or Dimensions tab (depending on your FreeCAD version).
  4. Locate the Line Width settings. You can set the exact millimeter thickness for:
    • Thin Line: Typically used for dimensions, hatching, and hidden lines (e.g., 0.18 mm or 0.25 mm).
    • Medium Line: Used for secondary features or annotations (e.g., 0.35 mm).
    • Thick Line: Used for primary visible outlines and borders (e.g., 0.5 mm or 0.7 mm).
  5. Locate the Line Pattern section to define default spacing for hidden, center, and phantom line dash arrays.
  6. Click Apply and OK to save the changes.

Customizing Lines for Specific Views and Edges

You can override global styles directly on individual views or selected geometric edges.

For an Entire View:

  1. In the Tree View, select the TechDraw view you want to modify.
  2. In the Property View panel below the tree, switch to the View tab.
  3. Modify the relevant line attributes:
    • Line Width: Enter a custom width value in millimeters.
    • Line Style: Choose from standard styles such as Continuous, Dashed, Dotted, or DashDot.
    • Hidden Line Color / Width / Style: Configure these options to visually distinguish non-visible edges.

For Individual Edges:

  1. Open the drawing page containing the part.
  2. Select the specific edge or segment you wish to alter directly on the page.
  3. In the TechDraw toolbar, click the Change Edge Appearance tool (or right-click the edge and choose appearance settings).
  4. Set custom parameters for Color, Line Width, and Line Style.
  5. Click OK to apply the overrides to the selected geometry only.

Creating Custom Line Groups via CSV

FreeCAD TechDraw uses external CSV configuration files to manage standardized line groups (such as ISO, ASME, or custom company standards).

  1. Navigate to the FreeCAD resource directory containing TechDraw templates and line definitions (typically located under FreeCAD/Mod/TechDraw/LineGroup or your user data directory).
  2. Open an existing .csv line group file (such as LineGroup.csv) in a plain text editor or spreadsheet program.
  3. Define custom rows using the following standard format:
    • GroupName: Unique name for the style set.
    • VisibleLine: Width in mm and dash pattern definition.
    • HiddenLine: Width in mm and dash pattern definition.
    • CenterLine: Width in mm and dash pattern definition.
  4. Save the file with a distinct name (e.g., Custom_LineGroup.csv).
  5. In FreeCAD, go to Edit > Preferences > TechDraw > General.
  6. Under Line Group File, browse to and select your custom .csv file.
  7. Views configured to use Line Groups will now adhere to your custom definitions automatically.
