How to Create a Detail View in FreeCAD TechDraw

A detail view in technical drafting is an enlarged representation of a specific section of a larger view, used to highlight complex features, add precise dimensions, and improve overall drawing legibility. This article explains the technical purpose of a detail view and provides a clear, step-by-step process for generating, positioning, and configuring detail views using the FreeCAD TechDraw Workbench.

What is a Detail View?

In engineering and manufacturing drawings, standard orthogonal or isometric views often contain small, intricate features that are difficult to see or dimension at the sheet's primary scale. A detail view isolates that specific area—typically identified by a circular callout and a letter reference (such as "Detail A")—and displays it at an enlarged scale elsewhere on the sheet. This prevents clutter in the main drawing views while providing manufacturing personnel with the clarity needed to inspect or fabricate small geometry.

Prerequisites

Before inserting a detail view in FreeCAD, ensure you have:

  1. A 3D model designed in an environment such as the Part or Part Design Workbench.
  2. An active TechDraw page containing at least one base projection view (the parent view) of your model.

Steps to Generate a Detail View

  1. Select the Parent View: In the 3D view area or the Tree View, click on the existing drawing view from which you want to create a detail.
  2. Activate the Detail View Tool: Switch to the TechDraw Workbench via the workbench dropdown. In the toolbar, click the Insert Detail View button (represented by an icon showing an enlarged circular view cutout).
  3. Configure the Detail Parameters: A dialog or task panel will open allowing you to specify the view properties:
    • Base View: Confirms the parent view being referenced.
    • Anchor Point (X, Y): Defines the coordinate center of the detail area relative to the parent view origin. You can adjust these values manually to position the circular crop over the target feature.
    • Radius: Sets the size of the circular area captured from the parent view.
    • Scale: Sets the magnification factor (for example, setting the scale to 2.0 creates a 2:1 enlargement of the parent view).
  4. Confirm Creation: Click OK. FreeCAD will generate the circular outline on the parent view and place the enlarged detail view directly on the TechDraw sheet.

Positioning and Customizing the View

  • Moving the View: Click and drag the label or boundary of the new detail view to place it in a clear area of the drawing sheet.
  • Modifying Properties: Select the detail view in the Tree View and navigate to the Data tab in the Property View panel. From here, you can adjust:
    • AnchorPoint: Fine-tune the center location on the base view.
    • Radius: Expand or shrink the captured boundary.
    • Scale and ScaleType: Change magnification or switch between custom and page scales.
    • Reference: Change the identification label (e.g., from "A" to "B").
  • Adding Annotations: Once placed, you can apply TechDraw dimensioning tools directly to the vertices and edges within the detail view just as you would on standard projection views.
