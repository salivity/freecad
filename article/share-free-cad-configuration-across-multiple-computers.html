Share FreeCAD Configuration Across Multiple Computers

Sharing your FreeCAD configuration across multiple computers allows you to maintain identical user interfaces, custom toolbars, keyboard shortcuts, macros, and installed addons on every workstation you use. This guide outlines the two most effective methods to achieve this synchronization: using FreeCAD's native Preference Packs for manual transfer, and using cloud storage combined with symbolic links for automated, real-time synchronization across Windows, macOS, and Linux.

Method 1: Exporting and Importing Preference Packs

FreeCAD includes a built-in Preference Pack system designed to export and import user settings without manually moving files.

  1. Open FreeCAD on your source computer.
  2. Navigate to Edit > Preferences.
  3. Click on the Preference Packs tab.
  4. Click Save template..., enter a name for your pack, and select which configuration categories (General, Display, Workbenches, etc.) you want to include.
  5. Once saved, locate the generated preference pack folder in your FreeCAD user directory under the PreferencePacks subfolder.
  6. Copy this folder to a USB drive or cloud drive, place it in the PreferencePacks directory on the target computer, and apply it via Edit > Preferences > Preference Packs.

Method 2: Automated Syncing via Cloud Storage and Symlinks

For a fully automated setup that includes addons, workbenches, macros, and configuration settings, link FreeCAD's local directories to a cloud-synced folder (such as Dropbox, Nextcloud, Google Drive, or OneDrive).

1. Identify the FreeCAD Directories

FreeCAD stores configurations in specific paths depending on your operating system:

  • Windows:
    • Settings: %APPDATA%\FreeCAD\ (e.g., C:\Users\<Username>\AppData\Roaming\FreeCAD\)
  • Linux:
    • Settings: ~/.config/FreeCAD/
    • Data/Addons: ~/.local/share/FreeCAD/
  • macOS:
    • Settings: ~/Library/Preferences/FreeCAD/
    • Data/Addons: ~/Library/Application Support/FreeCAD/

The primary file containing your interface and tool settings is user.cfg.

2. Move the Configuration to Cloud Storage

  1. Close FreeCAD completely on all machines.
  2. Move your primary machine's FreeCAD configuration folder into your cloud storage folder (for example, D:\CloudStorage\FreeCAD_Config).

3. Create Symbolic Links on Each Computer

Create a symbolic link on each computer that points the default directory to your cloud-synced directory.

  • Windows (Command Prompt as Administrator):

    mklink /D "%APPDATA%\FreeCAD" "C:\path\to\your\cloud\FreeCAD_Config"

  • Linux:

    ln -s ~/path/to/your/cloud/FreeCAD_Config ~/.config/FreeCAD

  • macOS:

    ln -s ~/path/to/your/cloud/FreeCAD_Config ~/Library/Preferences/FreeCAD

Important Considerations

  • Version Parity: Ensure all linked computers run the same minor version of FreeCAD (e.g., all on 0.21 or all on 1.0) to prevent user.cfg parameter conflicts or corruption.
  • Simultaneous Use: Do not run FreeCAD on multiple machines simultaneously, as both instances will attempt to write to user.cfg upon closing, causing cloud file conflicts.
  • Platform Differences: If you sync across different operating systems (e.g., Windows to Linux), absolute file paths configured for external renderers or custom macro directories inside user.cfg may need to be adjusted or set relative to FreeCAD paths.
