How to Reset FreeCAD to Default Settings

This guide explains how to restore FreeCAD to its original factory settings by removing or resetting its user configuration files. Because FreeCAD automatically generates fresh default configuration files whenever existing ones are missing, clearing these files from your system will instantly undo all personalized workbenches, toolbars, shortcuts, and interface customizations across Windows, macOS, and Linux.

Step 1: Completely Close FreeCAD

Before modifying or deleting any configuration files, ensure that FreeCAD is completely closed. If the application is running while you delete these files, it may overwrite your changes and recreate corrupted settings upon closing.

Step 2: Locate the Configuration Directory

FreeCAD stores all user preferences—including user.cfg and system.cfg—in specific directories depending on your operating system. Navigate to the appropriate location:

Windows

  1. Press Win + R to open the Run dialog.
  2. Type %APPDATA%\FreeCAD and press Enter.
  3. Path: C:\Users\<YourUsername>\AppData\Roaming\FreeCAD\

macOS

  1. Open Finder.
  2. Press Cmd + Shift + G to open the "Go to Folder" prompt.
  3. Enter: ~/Library/Preferences/FreeCAD/ or ~/Library/Application Support/FreeCAD/ and press Return.

Linux

  1. Open your terminal or file manager.
  2. Navigate to: ~/.config/FreeCAD/
    (Note: If you use the Flatpak version, check ~/.var/app/org.freecadweb.FreeCAD/config/FreeCAD/. If using Snap, check ~/snap/freecad/current/.config/FreeCAD/.)

Step 3: Delete or Rename the Configuration Files

To perform a full reset:

  1. Recommended (Safe Method): Rename the FreeCAD folder to FreeCAD_backup. Renaming keeps your old settings and macros intact in case you need to recover custom macros or scripts later.
  2. Alternative (Hard Reset): Select and delete the user.cfg and system.cfg files within the FreeCAD folder.

If you also wish to clear cached application data, navigate to the local cache directory and delete the FreeCAD cache folder:

  • Windows: %LOCALAPPDATA%\FreeCAD\
  • macOS: ~/Library/Caches/FreeCAD/
  • Linux: ~/.cache/FreeCAD/

Step 4: Restart FreeCAD

Launch FreeCAD. The application will detect that no configuration files exist and will automatically generate clean, factory-default settings. All toolbars, preferences, view presets, and workbenches will be restored to their original out-of-the-box state.
