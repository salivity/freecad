Align Multiple Points Vertically in FreeCAD

Aligning multiple points along a vertical axis in a FreeCAD sketch ensures proper geometric alignment and prevents unintended movement during parametric modeling. This guide explains how to use FreeCAD’s Sketcher constraints—specifically the vertical constraint and construction lines—to align two or more points vertically in a few straightforward steps.

Method 1: Using the Vertical Constraint Directly

The fastest way to align points vertically in modern versions of FreeCAD is to apply the vertical constraint directly to the points.

  1. Open the Sketch: Double-click your sketch in the tree view to enter the Sketcher workbench edit mode.
  2. Select the Points: Click the first point, hold down the Ctrl key (or Cmd on macOS), and click every other point you want to align. Alternatively, drag a selection box around the target points.
  3. Apply the Vertical Constraint:
    • Click the Constrain vertically icon in the Sketcher toolbar (represented by a vertical line with red endpoints), or
    • Press the keyboard shortcut V.

FreeCAD will automatically adjust the positions of the selected points so they share the exact same X-coordinate, locking them into a vertical column.

Method 2: Aligning to a Vertical Construction Line

If you are working with complex geometry or older versions of FreeCAD where multi-point vertical constraints are restricted to pairs, using a construction line offers a flexible alternative.

  1. Toggle Construction Mode: Click the Toggle construction geometry icon in the Sketcher toolbar (the icon switches from white to blue geometry).
  2. Draw a Vertical Line:
    • Select the Create a line tool.
    • Draw a line near the points you want to align.
    • Select the line and press V to ensure it is strictly vertical.
  3. Attach Points to the Line:
    • Toggle construction mode off.
    • Select your first point, select the vertical construction line, and press the Constrain point onto object shortcut (O).
    • Repeat this process for all other points.

All constrained points will now slide along the same vertical reference line.

Important Tips

  • Over-Constraining: If applying a vertical constraint causes the sketch to turn orange or red, the sketch is over-constrained. This occurs if one or more of the points are already fixed in position by existing horizontal, coincident, or distance constraints. Check the "Solver messages" panel in the Tasks tab to identify and remove the conflicting constraint.
  • Master Point: To control where the vertical line sits relative to the rest of the model, apply a horizontal distance constraint between the sketch origin (or an existing feature) and one of the vertically aligned points. All aligned points will move together horizontally.
