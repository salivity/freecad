Share FreeCAD Assemblies with External Parts

Sharing a FreeCAD assembly containing external parts requires preserving the file paths between the master assembly and its linked components to prevent broken references. The most reliable approach for full parametric editing is packaging a dedicated project directory with relative file paths into a compressed archive. Alternatively, depending on the recipient's needs, you can embed external components directly into a single file or export the entire model as a standardized STEP assembly.

Method 1: The Relative Folder Archive (Best for Full Parametric Editing)

FreeCAD resolves file links using relative paths whenever external parts reside in the same folder as the assembly file, or within a subfolder directly beneath it.

  1. Create a dedicated project directory on your computer.
  2. Save your master assembly file inside this root folder.
  3. Save all linked .FCStd component files within this folder or a dedicated subfolder (such as Parts/).
  4. Link the parts into your assembly workbench (such as FreeCAD 1.0 Assembly, Assembly3, or Assembly4) using these relative locations.
  5. Compress the entire project directory into a single .zip or .7z file.

When the recipient extracts the archive, the relative directory structure remains intact, allowing FreeCAD to resolve all references without manual remapping.

Method 2: Embedding Linked Files into a Single Document

If you prefer sending a single .FCStd file without distributing separate part files, convert external links into internal objects:

  1. Select the linked part within the tree view.
  2. In the Property panel, review the Link properties.
  3. Convert or import the external shape directly into the document so that the geometry data is saved inside the master assembly file itself.
  4. Save the master assembly file and share it as a standalone document.

This method eliminates missing path errors entirely, though changes made to the original source parts will no longer automatically update the assembly.

Method 3: Exporting to STEP AP214 or AP242 (Best for Interoperability)

When sharing assemblies with users on other CAD platforms, or when parametric history is not required:

  1. Select the root assembly object in the tree view.
  2. Go to File > Export and choose STEP with colors (.step .stp).
  3. In FreeCAD's Import/Export preferences, ensure that STEP export is set to AP214 or AP242 to preserve the assembly hierarchy and individual part colors.

The resulting single STEP file encapsulates all parts, their positions, and their visual properties, making it readable by nearly any modern 3D CAD application.
