FreeCAD Draft Move vs Standard Translation

In FreeCAD, moving an object can be achieved through either a standard translation or the Draft Move tool, but each serves a distinct role in modeling workflows. While a standard translation generally alters an object’s underlying numerical placement properties along fixed global or local axes, a Draft Move is an interactive, vector-based operation that utilizes snapping mechanisms to reposition objects or sub-elements relative to existing geometry. Understanding the functional differences between these two methods ensures accurate positioning, maintains parametric integrity, and speeds up design tasks.

Standard Translation (Placement and Transform)

Standard translation refers to modifying an object’s coordinates directly via its properties or FreeCAD's built-in 3D gizmo.

  • Placement Property: Every spatial object in FreeCAD has a Placement attribute in the Data tab. Changing the Base coordinates (X, Y, Z) shifts the object relative to its parent coordinate system.
  • Transform Tool: Accessed by right-clicking an object in the tree view and selecting "Transform," this tool provides an on-screen triad (gizmo) allowing users to drag objects along specific axes or rotate them in discrete increments.
  • Rigid Body Movement: Standard translation treats the object as an indivisible unit. It relocates the entire coordinate system of the object without altering its underlying geometric definitions or component vertices.
  • Parametric Considerations: If an object is controlled by an Attachment (common in the PartDesign workbench), standard translation fields may be overridden or locked, requiring adjustments through the Attachment Offset instead.

Draft Move (Draft_Move)

The Draft Move tool is part of FreeCAD's Draft workbench and functions more like traditional CAD moving commands found in architectural and 2D drafting software.

  • Vector and Snapping Integration: Instead of relying strictly on axis offsets, Draft Move defines displacement using two user-selected points: a start point and an end point. This allows seamless snapping to vertices, midpoints, centers, and intersections of existing geometry.
  • Sub-element Modification: For certain Draft and sketch-based shapes, Draft Move can move individual vertices or edges rather than the entire object, directly altering the shape's geometric structure.
  • Copy Capability: During the Draft Move command, a toggle in the task panel allows you to create a copy or clone of the selected object at the target location instead of simply displacing the original.
  • Working Plane Dependence: Draft Move operations are typically projected onto the currently active Draft Working Plane (e.g., Top, Front, Side, or custom surface), providing control over the plane of movement.

Key Differences at a Glance

  • Input Method: Standard translation relies on manual coordinate entry or dragging an axial gizmo. Draft Move uses interactive point-to-point vectors.
  • Precision and Referencing: Standard translation is ideal when you know the exact numerical distance along an axis. Draft Move is superior when aligning an object directly to an existing geometric feature without prior measurement.
  • Geometry vs. Coordinates: Standard translation purely updates the Placement.Base coordinates. Draft Move can alter placement or modify raw geometry depending on whether whole objects or sub-elements are selected.
  • Duplication: Standard translation only moves the existing object. Draft Move includes an integrated option to duplicate the object during displacement.

When to Use Each

Use Standard Translation when working within the PartDesign workbench, when adjusting feature offsets parametrically, or when moving parts by known, uniform mathematical values along a single axis.

Use Draft Move in layout design, architectural modeling, assembly alignment, or 2D drafting where an object needs to snap directly to the corner, edge, or midpoint of another geometric element.
