Where to Find FreeCAD Stable Release Notes

Finding the official release notes for new stable versions of FreeCAD is essential for tracking new features, workflow changes, and bug fixes. This guide outlines the primary official locations where the FreeCAD project publishes detailed release documentation, including the official documentation wiki, the GitHub repository, and community announcement channels.

The Official FreeCAD Wiki

The FreeCAD Wiki is the most comprehensive source for end-user release notes. When a major stable version is released, the community creates an illustrated and categorized document detailing UI overviews, core workbench modifications, and removed features.

  • Navigate to the main wiki at wiki.freecad.org.
  • Search for the specific version, such as "Release notes 1.0" or "Release notes 0.21".
  • You can also find a comprehensive list of all historical changes by viewing the "Release notes" category page directly on the wiki.

The GitHub Releases Page

For direct download links alongside the corresponding change logs, the project’s GitHub repository is the definitive technical source.

  • Visit the official FreeCAD repository on GitHub (github.com/FreeCAD/FreeCAD).
  • Click on the Releases section on the right side of the repository home page.
  • Stable releases are tagged with full version numbers (such as 1.0.0 or 0.21.2) and are marked as "Latest".
  • Each release entry contains a summary of notable changes, links to the commit logs, and the official release binaries for Windows, macOS, and Linux.

The Official FreeCAD Blog and News

High-level summaries highlighting the most impactful features are published as news articles on the official FreeCAD website.

  • Visit blog.freecad.org or the news section on freecad.org.
  • Major milestone releases receive a dedicated launch article detailing the state of the software, funding updates, and key additions aimed at everyday users.

The FreeCAD Community Forum

The FreeCAD Forum features an Announcements subforum where release candidates and finalized stable builds are officially posted.

  • Go to forum.freecad.org.
  • Check the "News & Announcements" category.
  • Pinned topics in this category provide release discussions, known regressions, and early workarounds immediately following a new stable launch.
