How to Change the FreeCAD Interface Language

This guide provides a straightforward walkthrough on how to change the display language of the FreeCAD user interface. Whether you need to switch to your native tongue or set the software to a specific language for tutorials, the steps below detail how to navigate the settings menu, select your preferred language, and apply the changes successfully.

Step 1: Open the Preferences Menu

Launch FreeCAD on your computer. Once the application loads, navigate to the Preferences dialog:

  • Windows and Linux: Click on Edit in the top menu bar, then select Preferences.
  • macOS: Click on FreeCAD in the top menu bar, then select Preferences (or press Cmd + ,).

Step 2: Locate the Language Settings

  1. In the Preferences window, ensure the General section is selected from the left-hand sidebar (indicated by a gear icon).
  2. Within the General settings panel, stay on the General tab.
  3. Locate the Language option, which features a drop-down menu showing the current interface language.

Step 3: Select Your Language and Apply

  1. Click the Language drop-down menu to view the list of available languages.
  2. Scroll through the list and select the language you want to use.
  3. Click the Apply button at the bottom right of the window, followed by OK to close the Preferences dialog.

Step 4: Restart FreeCAD (Recommended)

While many interface elements update immediately, some menus, workbench tools, and technical terms require a restart to reload the translation files properly. Close FreeCAD completely and reopen it to ensure the entire interface displays in your chosen language.
