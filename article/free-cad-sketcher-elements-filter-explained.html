FreeCAD Sketcher Elements Filter Explained

The Elements filter in the FreeCAD Sketcher dialog is a workflow tool designed to organize and manage the geometric components of a sketch. In complex designs containing dozens or hundreds of lines, arcs, and points, finding specific items in the 3D viewport can be difficult. The Elements filter allows you to narrow down the list of sketch entities displayed in the Sketcher task panel, making it easy to identify, select, troubleshoot, and modify specific geometry.

Purpose of the Elements List

Whenever you draw geometry in FreeCAD's Sketcher workbench, each item—whether it is a line, circle, arc, B-spline, or point—is automatically cataloged in the "Elements" list within the Tasks panel. Alongside the geometry type, each element is assigned an internal index number and an optional custom name.

What the Filter Does

The filter feature located above or within the Elements list dynamically refines which geometric items are displayed in the dialog based on specific criteria. Its primary functions include:

  • Filtering by Geometry Type: You can isolate specific categories of geometry, such as normal geometry (which forms the final solid features), construction geometry (used strictly for alignment and dimensioning), and external geometry (linked from external edges or faces).
  • Text-Based Searching: By typing a name or an element index (such as Edge12 or a custom label) into the search field, the list instantly filters down to matching results.
  • Isolating Problem Areas: In sketches with topological naming issues or broken references, filtering allows you to quickly locate missing, unconstrained, or orphaned elements that prevent the sketch from fully solving.

How It Improves Sketch Management

Using the Elements filter significantly speeds up editing in several ways:

  1. Bidirectional Selection: Clicking an element in the filtered list immediately highlights that element in the 3D viewport. Conversely, selecting an entity in the viewport automatically highlights it in the Elements list, provided it matches the active filter.
  2. Accessing Overlapping Geometry: When multiple lines, points, or coincident constraints overlap visually in the 3D view, clicking the exact entity you want can be nearly impossible. Filtering the Elements list lets you click the exact element name directly from the panel.
  3. Bulk Operations: With a filtered list, you can easily select multiple elements of the same type to change their properties at once, such as converting a group of normal lines into construction lines or deleting redundant references.
