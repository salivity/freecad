How to Insert Doors and Windows in FreeCAD Arch

Inserting doors and windows into walls in FreeCAD is a streamlined process managed primarily through the Arch or BIM Workbench. FreeCAD treats both doors and windows as "Window" objects that host parametric presets, which can be directly attached to an existing wall object to automatically generate the necessary opening cuts and frame geometry. This guide covers how to select presets, place components into host walls, and adjust their parametric properties.

Prerequisites

Before adding openings, ensure you have the BIM or Arch Workbench active (in FreeCAD 0.21 and later, Arch is integrated directly into the BIM workbench) and an existing Arch Wall modeled in your 3D view.

Step 1: Select the Host Wall

  1. Switch your active workbench to BIM or Arch.
  2. In the 3D view or the Tree view, select the wall into which you want to insert the door or window. Alternatively, you can select the specific exterior or interior face of the wall where the component should sit.

Step 2: Open the Window Tool

  1. Click the Window tool icon from the toolbar, or navigate to BIM/Arch → Window in the top menu.
  2. The Task panel will open on the left side of the screen, displaying preset options and dimensions.

Step 3: Choose a Preset

FreeCAD uses the same underlying tool for both doors and windows:

  • For Windows: Select a preset such as Simple window, Double opening, or Fixed.
  • For Doors: Select a door preset, such as Simple door or Glass door.

Step 4: Configure Dimensions and Placement

  1. In the Task panel, define the parametric values:
    • Width and Height: Set the overall dimensions of the frame.
    • Offset: Adjust the depth placement of the frame relative to the wall face.
  2. Move your cursor over the selected wall in the 3D view. FreeCAD will preview the component snapping to the wall's geometry.
  3. Click to place the door or window at the desired location along the wall.

Once placed, FreeCAD automatically creates a boolean subtraction within the host wall, cutting an opening matching the dimensions of the door or window frame.

Step 5: Adjusting Position and Properties

If you need to make changes after insertion:

  1. Repositioning: Select the window or door object in the Tree view. In the Data tab of the Properties panel below, expand the Placement property to fine-tune the X, Y, or Z coordinates along the wall.
  2. Resizing: Modify the Width, Height, or Hole Depth properties directly in the Data tab. The wall opening will automatically update to match the new dimensions.
  3. Opening Symbol (2D): To display swing directions in 2D floor plans, set the Opening property in the Data tab to an angle (e.g., 90°).
