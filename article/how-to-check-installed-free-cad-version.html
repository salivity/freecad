How to Check Installed FreeCAD Version

Checking your installed FreeCAD version is essential for troubleshooting issues, ensuring compatibility with workbenches, or determining if an update is required. This guide provides clear, step-by-step instructions to quickly find the version and build details of FreeCAD using either the graphical interface on any operating system or the command-line interface.

Method 1: Check via the FreeCAD Graphical Interface (All Platforms)

This method works consistently across Windows, macOS, and Linux.

  1. Launch FreeCAD.
  2. In the top menu bar, click on Help.
  3. Select About FreeCAD from the dropdown menu.
  4. A window will appear displaying the major version number, release date, and build information.
  5. (Optional) Click the Copy to clipboard button if you need to paste your complete system and build information into a forum or issue tracker for technical support.

Method 2: Check via the Command Line

If you are using a terminal or running FreeCAD in a headless environment, you can check the version directly from the console.

Windows

  1. Open Command Prompt or PowerShell.

  2. Navigate to your FreeCAD installation's bin folder (default is usually C:\Program Files\FreeCAD 0.XX\bin) or run:

    freecad --version

    (Note: This requires FreeCAD to be added to your system's PATH variable.)

Linux and macOS

  1. Open your Terminal.

  2. Run the following command:

    freecad --version

    If you have installed FreeCAD as a console-only tool, you can also run:

    freecadcmd --version

Flatpak or Snap (Linux)

If you installed FreeCAD as a sandbox package on Linux, run the appropriate command:

  • Flatpak:

    flatpak info org.freecadweb.FreeCAD

  • Snap:

    snap list freecad

Method 3: Check via System Settings

You can also determine the installed version through your operating system's native application managers:

  • Windows: Open Settings > Apps > Installed apps, locate FreeCAD, and view the version number listed next to the application name.
  • macOS: Open Finder, navigate to the Applications folder, click FreeCAD, and press Command + I to open the "Get Info" panel, which lists the version.
  • Linux (Debian/Ubuntu): Run dpkg -l | grep freecad in the terminal to view the installed repository package version.
