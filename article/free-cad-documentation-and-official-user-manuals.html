FreeCAD Documentation and Official User Manuals

This guide provides a straightforward overview of where to access official documentation, user manuals, and learning resources for FreeCAD. Whether you need an introduction for beginners, in-depth workbench references, or Python scripting guides, FreeCAD offers several official channels both online and directly within the application.

The Official FreeCAD Wiki

The primary repository for all official FreeCAD documentation is the FreeCAD Wiki (located at wiki.freecad.org). Maintained continuously by the developers and community, the wiki contains:

  • Workbenches Documentation: Detailed overviews of native workbenches like PartDesign, Sketcher, TechDraw, and Arch/BIM.
  • Getting Started Guides: Step-by-step tutorials covering core concepts such as parametric modeling, constraint-based sketching, and navigation styles.
  • Multilingual Support: Community translations available in numerous languages, selectable via the top navigation bar.

The FreeCAD User Manual

For users seeking a structured, book-style learning path rather than individual wiki pages, FreeCAD provides an official manual.

  • Available directly on the wiki under the "Manual" section, this guide walks users sequentially from installation and interface navigation to complex 3D modeling and 2D technical drawing generation.
  • An offline, downloadable version of the manual in PDF or ePub format can often be obtained from the official FreeCAD GitHub repository under the documentation releases.

In-App Help System

You can access official documentation without leaving the FreeCAD interface:

  • Help Menu: Open the application and navigate to Help > FreeCAD Help to launch the built-in documentation viewer.
  • Context-Sensitive Help: Hovering over tools or pressing F1 while selecting a command will often take you directly to the relevant documentation page for that specific tool.
  • Offline Documentation Package: Depending on your operating system or installation method (such as Flatpak, Conda, or standard installers), you may need to install the optional freecad-doc package to view help files without an active internet connection.

Python Scripting and Developer Documentation

For advanced users looking to automate workflows or develop custom workbenches:

  • The Power Users Hub on the official wiki covers Python scripting, macro creation, and custom GUI tools.
  • The Developer Hub hosts auto-generated source code documentation (Doxygen), providing full class and API references for C++ and Python development.
