Using Grid Snap in FreeCAD Draft Workbench

This article provides an overview of the grid snap function within the FreeCAD Draft workbench, detailing its primary purpose, operational mechanics, and practical applications. Readers will learn how grid snapping facilitates geometric accuracy in 2D and 3D modeling, how it integrates with custom working planes, and how to configure its settings for efficient drafting workflows.

The grid snap function in the FreeCAD Draft workbench is a precision-drawing tool that forces the cursor to latch onto predetermined intervals on the active coordinate grid. Instead of placing points freely in 3D space, grid snap constrains cursor placement strictly to the intersections of grid lines. This eliminates manual positioning errors and ensures dimensional consistency across technical drawings and 3D wireframe models.

Primary Uses of Grid Snap

  • Accurate Coordinate-Based Drawing: Grid snap allows designers to place points, lines, arcs, and polygons at precise, repeatable distances without manually typing coordinates into the numerical input fields.
  • Modular and Layout Design: In architectural and floor plan drafting, standard structural elements—such as walls, columns, and door placements—often conform to standard modular intervals (e.g., 100 mm, 500 mm, or 1 m). Grid snap simplifies laying out these repeated units quickly.
  • Rapid Prototyping in 2D: When sketching basic profiles or mechanical layouts, grid snap allows users to establish exact dimensions visually by counting grid subdivisions, drastically speeding up preliminary drafting.
  • Reference for Object Placement: It provides a reliable spatial reference when translating, rotating, or scaling existing shapes relative to one another.

How Grid Snap Operates

Grid snap works in tandem with the Draft Workbench's Working Plane. The grid automatically aligns with the active plane—such as the standard XY (Top), XZ (Front), or YZ (Side) planes—or can be mapped onto any custom face of an existing 3D solid.

When the grid snap toggle is activated in the Draft Snap toolbar or the Draft Tray at the bottom of the interface, the cursor calculates its proximity to the nearest grid intersection. Once within a defined snapping radius, FreeCAD snaps the input point to that intersection, visually indicating the snap with a dedicated grid snap marker.

Integration with Other Snapping Modes

While object snaps (such as snapping to endpoints, midpoints, or centers) rely on existing geometry, grid snap functions independently of any existing model geometry. It can be used alone to generate the initial foundation of a drawing, or concurrently with other snap modes to blend geometry-based references with absolute spatial constraints.

Customization and Control

Users can fully customize the behavior of the grid snap via the Draft preferences and the Draft Tray:

  • Grid Spacing: Sets the primary distance between main grid lines.
  • Subdivisions: Defines the number of smaller intervals between major grid lines for fine-detail work.
  • Visibility: The visual grid lines can be turned on or off without disabling the snap function itself, allowing users to draw with precision on a clean viewport.
  • Shortcut Toggling: Grid snapping can be quickly toggled on and off using the snap toolbar, allowing for seamless transitions between freehand placement, geometry snapping, and grid-locked input.
