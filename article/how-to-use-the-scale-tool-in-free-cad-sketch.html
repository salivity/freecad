How to Use the Scale Tool in FreeCAD Sketch

Scaling geometry within the FreeCAD Sketcher allows you to resize 2D elements proportionally without redrawing them from scratch. This guide walks through the exact steps to locate the Scale tool, select your geometry, set a center reference point, and apply the scaling factor directly inside an active sketch.

Step 1: Open Your Sketch in Edit Mode

Ensure you are inside the Sketcher Workbench. Double-click your sketch in the tree view to enter edit mode. You should see the sketch grid and existing geometric entities (lines, circles, arcs).

Step 2: Select the Geometry to Scale

Use the selection tool (default mouse cursor) to highlight the elements you wish to resize.

  • To select multiple elements, hold Ctrl and click each element.
  • Alternatively, click and drag a selection box around the entire profile you want to resize.

Step 3: Activate the Scale Tool

With your elements highlighted, access the tool:

  1. Locate the Sketcher tools toolbar.
  2. Click the dropdown arrow next to the Clone or Move tool icon.
  3. Select Scale (represented by an icon showing geometry expanding outward). Alternatively, you can go to the top menu and navigate to Sketch > Sketcher tools > Scale.

Step 4: Pick the Base Center Point

Once the tool is active, the cursor prompts for a reference point:

  1. Click in the 3D view to choose the center point of scaling. This point serves as the anchor; geometry will expand away from or shrink toward this location.
  2. For predictable results, choose an existing vertex, the sketch origin (0,0), or the geometric center of your profile.

Step 5: Define the Scale Factor

After choosing the base point:

  1. Click a starting reference point to establish the initial distance from the base point.
  2. Move your cursor away from or toward the base point to dynamically preview the scaled geometry.
  3. Click a second time to complete the transformation, or type specific coordinates in the task panel if prompted by your FreeCAD version.

Handling Constraints After Scaling

  • Unconstrained Geometry: Resizes smoothly to the new size.
  • Constrained Geometry: If elements contain strict dimensional constraints (such as fixed lengths or radius constraints), FreeCAD may display a solver error or over-constrained warning. It is best practice to delete or temporarily disable rigid dimensional constraints before scaling, then reapply appropriate dimensions to the newly sized shape.
