Create Architectural Section Cuts in FreeCAD

Creating section cuts through an architectural model in FreeCAD allows you to inspect interior details and generate 2D construction drawings like plans, elevations, and cross-sections. This guide covers how to set up and position a Section Plane using the BIM workbench, configure its cut properties, and output the result to 2D views or documentation sheets, as well as how to perform quick 3D visual cuts using clipping planes.

Method 1: Using the Section Plane Tool (For 2D Drawings and Documentation)

The primary way to create permanent, exportable section cuts in architectural projects is through the Section Plane tool.

  1. Switch to the BIM Workbench
    • Open your architectural project in FreeCAD.
    • In the workbench dropdown menu, select BIM (or Arch if using an older version of FreeCAD).
  2. Insert a Section Plane
    • Ensure no objects are selected, or select the specific building/objects you want to slice.
    • Click the Section Plane button on the BIM toolbar (or navigate to BIM > Section Plane).
    • A transparent rectangular plane appears in your 3D view, indicating the cut plane and the viewing direction (represented by an arrow).
  3. Position and Rotate the Cut
    • Select the Section Plane in the tree view.
    • In the Property View panel under the Data tab, expand the Placement property.
    • Adjust the Position (X, Y, Z coordinates) to place the cut at the desired elevation or room location.
    • Adjust the Rotation or use the Draft Move and Draft Rotate tools to orient the plane horizontally for floor plans or vertically for cross-sections.
  4. Adjust Cut Settings
    • In the Data tab of the Section Plane, modify key parameters:
      • Cut: Set to True if you want the 3D model itself to appear visually cut in the viewport.
      • Objects: Specify which objects are included in the cut (leave blank to include all visible elements).
      • Depth: Define how far past the section plane objects should remain visible (set to 0 for infinite depth).
  5. Generate a 2D Drawing from the Section
    • For 2D Line Art in 3D Space: Select the Section Plane and run the Draft Shape2DView tool to create a flattened 2D projection on the working plane.
    • For TechDraw Sheets: Switch to the TechDraw Workbench, create or open a drawing page, select the Section Plane in the tree, and click Insert Arch View to project the cross-section directly onto your printable title sheet.

Method 2: Using the 3D Clipping Plane (For Fast Inspection)

If you only need a temporary visual cut to inspect internal geometry without creating drawing outputs:

  1. Go to the top menu and select View > Clipping plane.
  2. In the Clipping Plane panel on the left, check the axis you want to cut along (X, Y, or Z), or choose Custom.
  3. Use the slider or enter a value in the distance field to shift the plane through the model.
  4. Click Flip to invert which side of the model is hidden.
  5. Click Close when finished to restore the normal view.
