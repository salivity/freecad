How to Install FreeCAD on Linux Using AppImage

Installing FreeCAD on Linux using an AppImage is one of the fastest and most reliable methods to run the open-source 3D parametric modeler. This guide walks you through downloading the official AppImage, granting the necessary execution permissions, and running FreeCAD on virtually any modern Linux distribution without complex dependency configurations.

Step 1: Download the FreeCAD AppImage

  1. Go to the official FreeCAD website's download section.
  2. Select the Linux AppImage option (typically a 64-bit .AppImage file).
  3. Save the file to an accessible directory, such as ~/Downloads or an application folder like ~/Applications.

Step 2: Make the File Executable

Linux requires explicit permission to execute downloaded AppImage files. You can grant execution rights using either the graphical interface or the command line.

Method A: Using the Graphical Interface (GUI)

  1. Open your file manager and locate the downloaded .AppImage file.
  2. Right-click the file and select Properties.
  3. Navigate to the Permissions tab.
  4. Check the box labeled Allow executing file as program (or set Access to Read and Write and enable execution, depending on your desktop environment).
  5. Close the Properties window.

Method B: Using the Terminal

  1. Open your terminal.

  2. Navigate to the directory containing the downloaded file:

    cd ~/Downloads

  3. Run the following command to make the file executable:

    chmod +x FreeCAD*.AppImage

Step 3: Launch FreeCAD

Once marked as executable, you can run the program immediately:

  • GUI: Double-click the .AppImage file in your file manager.

  • Terminal: Run the executable directly by entering:

    ./FreeCAD*.AppImage

FreeCAD will launch without installing files across your system directories.

Optional: Desktop Integration

If you want FreeCAD to appear in your desktop application menu alongside your other installed programs:

  1. Use AppImageLauncher: Install the utility AppImageLauncher for your Linux distribution. When you double-click an AppImage, it will prompt you to automatically integrate the program into your system menu and move it to a centralized folder.
  2. Manual Desktop Entry: Create a .desktop shortcut file in ~/.local/share/applications/ pointing to the path of your FreeCAD AppImage.
