How to Export FreeCAD Sketch to SVG and DXF

Exporting sketch data from FreeCAD into external vector graphic formats like SVG, DXF, and PDF allows you to transition your 2D designs to laser cutters, CNC machines, or graphic design software. FreeCAD provides multiple methods to accomplish this, ranging from direct file exports to utilizing dedicated workbenches like TechDraw for dimensioned, scaled layouts. This guide covers the fastest and most reliable methods to extract your sketch data as clean vector files.

Method 1: Direct File Export

The fastest way to export raw sketch geometry is through FreeCAD's native export menu.

  1. In the Tree View on the left panel, click on the Sketch you want to export to highlight it.
  2. Go to the top menu and select File > Export (or press Ctrl + E / Cmd + E).
  3. In the export dialog, click the Files of type dropdown menu.
  4. Select your desired vector format:
    • **Flattened SVG (*.svg):** Best for graphic software (such as Inkscape or Adobe Illustrator) and laser cutters.
    • **Autodesk DXF (*.dxf):** Ideal for CAD/CAM workflows, CNC routing, and waterjet cutting.
  5. Choose your destination folder, enter a file name, and click Save.

Method 2: Exporting via the TechDraw Workbench

If you need precise 1:1 scale control, line weight adjustments, or want to include annotations and dimensions alongside the vector geometry, use the TechDraw workbench.

  1. Switch to the TechDraw Workbench via the workbench dropdown.
  2. Click Insert Default Page (the orange folder icon with a plus sign) to create a new drawing sheet.
  3. Select your sketch in the Tree View, then click Insert View in the TechDraw toolbar.
  4. With the view selected in the sheet properties, set the Scale to 1.0 (1:1) to preserve exact real-world dimensions.
  5. Turn off unwanted elements such as borders or frame templates if you only need the raw vector paths.
  6. Export the drawing:
    • Go to TechDraw > Page > Export SVG to save as an SVG.
    • Go to TechDraw > Page > Export DXF to save as a DXF.

Format Considerations

  • SVG Units: External software like Inkscape often renders SVGs based on display pixels (96 DPI). When importing, verify that your document properties match the source scale of FreeCAD (millimeters).
  • DXF Compatibility: FreeCAD includes a built-in C++ DXF exporter, but you can configure legacy DXF libraries under Edit > Preferences > Import-Export > DXF if you require older AutoCAD release formats (such as R12 or R14) for legacy CNC machine controllers.
  • Closed Profiles: Ensure your sketch is fully constrained and has closed profiles without overlapping vertices if your downstream workflow requires path tracing, extrusions, or G-code generation.
