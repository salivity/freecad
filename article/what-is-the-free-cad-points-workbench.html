What Is the FreeCAD Points Workbench?

The FreeCAD Points workbench is a dedicated toolset designed for reading, inspecting, and manipulating 3D point clouds within the FreeCAD ecosystem. This article outlines the workbench's core purpose, its primary tools for managing raw coordinate data from 3D scanners and LiDAR devices, and how it integrates into broader reverse engineering workflows to transform point data into usable solid CAD models.

Purpose of the Points Workbench

The primary purpose of the Points workbench is to bridge the gap between real-world physical objects and digital parametric models. When physical parts, buildings, or terrains are scanned using 3D scanners, LiDAR, or photogrammetry software, the output is typically a point cloud—a collection of millions of individual data points residing in a shared 3D coordinate system.

Because standard CAD modeling workbenches in FreeCAD rely on parametric solids, boundary representations (B-rep), or geometric meshes, they are not optimized to handle vast arrays of unstructured points. The Points workbench provides the specialized tools needed to import, organize, and prepare this raw scan data without overwhelming system resources.

Core Capabilities and Features

1. File Import and Export

The workbench supports common point cloud formats, including:

  • ASC / XYZ: Plain text files containing raw X, Y, and Z coordinate data.
  • PCD: Point Cloud Data format, standard in robotics and 3D perception applications.
  • PLY: Polygon File Format, often used for storing 3D scan data.

It allows users to import these datasets directly into the 3D viewer and export modified or filtered clouds back into standard formats.

2. Point Cloud Inspection

Users can interactively evaluate scanned objects directly in the viewport. The workbench enables users to:

  • View point coordinates and overall bounding dimensions.
  • Verify orientation and spatial alignment relative to the global origin.
  • Check data density and distribution to identify gaps in scan coverage.

3. Basic Editing and Preparation

Raw point clouds often contain noise, unnecessary background elements, or excessive points that make rendering sluggish. The Points workbench provides basic utility functions to:

  • Cut and trim away unwanted sections of the cloud.
  • Subsample large datasets to reduce point counts while preserving the general shape of the scanned geometry.
  • Merge multiple point sets into a single unified cloud.

Role in the Reverse Engineering Workflow

The Points workbench is rarely the final step in a design project. Instead, it serves as the foundational stage of a reverse engineering pipeline:

  1. Acquisition: A physical object is scanned, generating a point cloud.
  2. Preparation (Points Workbench): The point cloud is imported, cleaned of noise, oriented, and subsampled.
  3. Triangulation (Mesh Workbench): The prepared points are converted into a continuous polygonal mesh via surface reconstruction algorithms.
  4. Parametric Modeling (Reverse Engineering / Part Design Workbench): The mesh geometry is referenced to create precise parametric sketches, surfaces, and solids.

By isolating point cloud management into its own module, FreeCAD maintains high performance and provides a clean, focused environment for the first stage of physical-to-digital translation.
