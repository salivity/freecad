Project 3D Objects to 2D in FreeCAD Draft

Projecting a 3D object onto a 2D plane in FreeCAD is a straightforward process primarily handled by the Shape 2D View tool within the Draft Workbench. This guide explains how to orient your model, generate a flat 2D projection from a 3D part, and configure the projection settings for drafting, technical drawing, or vector export.

Step 1: Switch to the Draft Workbench

  1. Open your document containing the 3D object in FreeCAD.
  2. In the workbench selector dropdown at the top of the interface, select Draft.

Step 2: Orient the View or Set the Working Plane

The 2D projection direction depends on your current view or the active working plane:

  • Option A (Camera View): Rotate your 3D view so you are looking directly at the face or angle you want to project (e.g., using standard views like Top, Front, or Isometric by pressing keys 1, 2, or 0).
  • Option B (Working Plane): Set the Draft Working Plane to the specific plane you want to project onto (such as XY, XZ, or YZ) using the Working Plane button on the Draft toolbar.

Step 3: Create the 2D Projection

  1. In the Tree view, select the 3D object (Part, Body, or Shape) you wish to project.
  2. Go to the top menu and select Draft → Modification → Shape 2D View, or click the Shape 2D View icon on the Draft toolbar.
  3. A new object labeled Shape2DView will appear in the Tree view, and a flat 2D projection will be placed on the active plane in the 3D viewport.

Step 4: Adjust Projection Properties

Select the newly created Shape2DView in the Tree view and navigate to the Data tab in the Property View panel to fine-tune the output:

  • Projection: Sets the vector along which the object is projected. By default, it uses the camera direction at creation. You can manually adjust the (X, Y, Z) coordinates to change the projection vector.
  • Projection Mode: Choose between Solid, Individual Faces, or Cutlines depending on whether you need solid outlines or sectional outlines.
  • In Face: Determines whether faces are generated as filled planes or just wireframes.
  • Tessellation: Enables approximation for complex curved surfaces if standard projection fails or creates artifacts.

Step 5: Utilize the 2D Geometry

Once generated, the 2D shape behaves like any standard Draft wire or face:

  • Move it to a separate layer or hide the original 3D model by selecting the 3D body and pressing the Spacebar.
  • Export the 2D geometry for CNC or CAD applications by selecting the Shape2DView and going to File → Export, then choosing formats such as DXF or SVG.
