How to Reset Sketch Plane Orientation in FreeCAD

Resetting the orientation of a sketch plane in FreeCAD is essential when a sketch is attached to the wrong face, inverted, or misaligned due to model changes. This guide provides direct, step-by-step instructions to reset or reorient a sketch plane using the Map Mode tool, the Reorient Sketch feature, and the Placement properties in the Part Design and Sketcher workbenches.

Method 1: Using the Map Mode Dialog (Recommended)

The Map Mode dialog is the most robust way to reattach or change the orientation of a sketch that is already mapped to geometry.

  1. In the Model tree, select the sketch you want to reorient.
  2. In the Property view (usually in the bottom-left panel), click the Data tab.
  3. Locate the Map Mode property under the Attachment group.
  4. Click the ellipsis button (...) that appears next to the current Map Mode value to open the Sketch attachment task panel.
  5. In the task panel, you can:
    • Select a new reference face or a base coordinate plane (XY_Plane, XZ_Plane, or YZ_Plane).
    • Change the attachment method (such as Flat face, Normal to edge, or Deactivated).
    • Use the Attachment Offset section below to adjust the Yaw, Pitch, and Roll angles, or check the Flip sides option to invert the normal direction.
  6. Click OK to apply the new orientation.

Method 2: Using the "Reorient Sketch" Tool

This method works specifically for sketches that are mapped to standard coordinate planes or are detached from specific solid faces.

  1. Select your sketch in the tree view.
  2. If the sketch is currently attached to a face, you must first detach it:
    • Go to the Data tab in the Property view.
    • Set Map Mode to Deactivated.
  3. With the sketch selected, go to the top menu and select Sketch > Reorient sketch (or click the Reorient sketch icon in the toolbar).
  4. A dialog box will appear asking to select the new orientation plane (XY-Plane, XZ-Plane, or YZ-Plane).
  5. Check or uncheck Reverse direction if the sketch is facing the wrong way.
  6. Click OK to confirm.

Method 3: Resetting via Attachment Offset

If the sketch is mapped correctly to the desired plane or face but is rotated incorrectly relative to the local axes:

  1. Select the sketch in the tree view.
  2. Go to the Data tab in the Property view.
  3. Expand the Attachment Offset property.
  4. Set the Angle property to 0.00°, or modify the Axis values back to their defaults (e.g., [0, 0, 1] for rotation around the Z-axis).
  5. Alternatively, adjust the Yaw, Pitch, or Roll fields in 90-degree increments to snap the sketch to the desired alignment.
  6. Press F5 or click Refresh in the toolbar to recompute the document.
