Create a Grid of Points in a FreeCAD Sketch

Creating a grid of points within a FreeCAD sketch is a straightforward process achieved by using the Sketcher workbench's native Rectangular Array tool. This guide provides a direct, step-by-step walkthrough for placing an initial point, utilizing the array feature to define rows and columns, and adjusting the spacing to produce a fully constrained, precise point grid directly on your sketch plane.

Step 1: Create or Open a Sketch

  1. Open your project in FreeCAD and switch to the Part Design or Sketcher workbench.
  2. Create a new sketch on your desired plane (e.g., XY-Plane) or double-click an existing sketch in the model tree to enter edit mode.

Step 2: Place the Initial Point

  1. Select the Create a point tool from the toolbar (or press the G then I shortcut keys).
  2. If you want the points to serve only as alignment references rather than geometry that affects features like pads or pockets, toggle the Construction Mode icon (blue geometry) before placing the point.
  3. Click anywhere in the sketch area to drop your first point. This will serve as the origin of your grid.

Step 3: Use the Rectangular Array Tool

  1. Switch back to normal selection mode and select the point you just created by clicking on it.
  2. In the toolbar, locate and click the Rectangular Array tool (found under the array/transform dropdown in the Sketcher tools).
  3. A dialog box will appear asking for the array parameters:
    • Columns: Enter the number of points you want horizontally.
    • Rows: Enter the number of points you want vertically.
    • Equal vertical/horizontal spacing: Check this option if you want the distance between rows and columns to be identical.
    • Constrain inter-element distance: Check this box so FreeCAD automatically creates dimensional constraints between the points.
    • Clone: Uncheck if you want individual points, or keep checked based on your preference.
  4. Click OK.

Step 4: Position and Size the Grid

  1. Move your cursor to the sketch area. You will see a preview of the grid attached to your cursor.
  2. Click once to set the direction and initial spacing of the array.
  3. Double-click the automatically generated dimensional constraint values to set the exact distance between columns (horizontal pitch) and rows (vertical pitch).
  4. Apply standard geometric constraints (such as fixing the first point to the sketch origin or using horizontal/vertical distances from reference axes) to fully constrain the grid.
