FreeCAD Color and Texture Export File Formats

FreeCAD is primarily a parametric CAD modeler focused on dimensional geometry, but several export formats allow you to preserve color and texture data for rendering, 3D printing, or asset exchange. While standard CAD formats typically ignore or limit surface appearances, mesh-based and scene description formats can carry face colors, material properties, and UV-mapped textures. This guide covers the file formats that support color and texture export from FreeCAD, along with the specific visual properties each format retains.

Formats Supporting Both Color and Textures

  • Wavefront OBJ (.obj): OBJ is one of the most reliable formats for exporting geometric meshes with visual data from FreeCAD. When exported, FreeCAD generates an accompanying .mtl (material template library) file. This format preserves diffuse colors assigned to faces and bodies. If you apply textures using workbenches like Arch, BIM, or Mesh Design, the UV coordinates and texture map links are stored in the OBJ and MTL files.

  • COLLADA (.dae): COLLADA is designed for interactive 3D applications and digital asset exchange. It natively supports scene hierarchies, material definitions, face colors, and mapped image textures. It is an ideal format when moving assets from FreeCAD to digital content creation software like Blender.

  • glTF / GLB (.gltf, .glb): glTF is a modern standard for 3D web delivery and real-time engines. It supports PBR (Physically Based Rendering) materials, surface colors, and embedded textures. In FreeCAD, glTF export is available directly through the BIM workbench or via add-ons, making it a compact choice for preserving full visual fidelity.

  • VRML 2.0 / X3D (.wrl, .x3d): Virtual Reality Modeling Language (VRML) and its successor X3D support RGB color per face, vertex colors, and basic texture wrapping. FreeCAD natively exports VRML, retaining color assignments applied to individual faces in the Part and Part Design workbenches.

Formats Supporting Color Only (No Image Textures)

  • STEP AP214 and AP242 (.step, .stp): While STEP does not support bitmap image textures, the AP214 and AP242 application protocols support solid body colors and individual face colors while preserving exact mathematical NURBS geometry. FreeCAD can read and write these colors if the STEP export preferences are set to use AP214 or AP242 instead of the geometry-only AP203 standard.

  • 3D Manufacturing Format (.3mf): Designed for modern additive manufacturing, 3MF supports multi-color 3D printing data, including per-face color assignment and material definitions. While the format specification allows textures, FreeCAD's native export focuses primarily on retaining solid color data and mesh fidelity.

  • Polygon File Format (.ply): PLY supports mesh geometry alongside vertex-level and face-level color information. It is suitable for point clouds and polygonal meshes with baked color data, but it does not support UV-mapped image textures from FreeCAD.

Key Considerations for Exporting Visual Data

To ensure colors and textures export correctly from FreeCAD, convert solid bodies to meshes using the Mesh Design workbench if you intend to export to .obj, .dae, or .x3d. For color-coded CAD models where geometric accuracy is required, always use STEP AP214 via the Part workbench rather than mesh formats.
