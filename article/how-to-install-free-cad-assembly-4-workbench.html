How to Install FreeCAD Assembly4 Workbench

The FreeCAD Assembly4 workbench is an essential external add-on designed to create mechanical assemblies using coordinate systems and parametric attachments. This guide provides a clear, step-by-step procedure to locate, install, and activate the Assembly4 workbench using FreeCAD’s integrated Addon Manager, ensuring you can quickly incorporate advanced multi-part modeling into your workflow.

Prerequisites

Before beginning, ensure that you have FreeCAD (version 0.19, 0.20, 0.21, or newer) installed and connected to the internet, as the Addon Manager retrieves external workbenches directly from online repositories.

Step 1: Open the Addon Manager

  1. Launch your FreeCAD application.
  2. In the top navigation menu, click on Tools.
  3. Select Addon Manager from the dropdown list. A new dialog box will open displaying all available workbenches, macros, and preferences packs.

Step 2: Locate Assembly4

  1. Inside the Addon Manager, make sure the Workbenches tab is selected.
  2. In the search bar at the top or bottom of the window, type Assembly4.
  3. Locate Assembly4 in the filtered list of available extensions.

Step 3: Install the Workbench

  1. Click on the Assembly4 entry in the list to select it and view its details.
  2. Click the Install button located in the top right corner of the Addon Manager window.
  3. FreeCAD will download the necessary files from the repository and install them into your local configuration directory. Wait for the download and extraction processes to complete.

Step 4: Restart FreeCAD

  1. Once the installation finishes, the Addon Manager will display a status message confirming that the workbench is installed.
  2. A prompt will appear asking you to restart FreeCAD to apply the changes. Click Restart.
  3. If no automatic prompt appears, close the Addon Manager and manually restart the application.

Step 5: Verify the Installation

  1. After FreeCAD restarts, look at the Workbench selection dropdown menu on the main toolbar (which typically defaults to "Start" or "Part Design").
  2. Click the dropdown menu and scroll through the alphabetical list.
  3. Select Assembly4.

The main interface will now load the Assembly4 toolbar, commands, and menus, confirming that the workbench is ready for use.
