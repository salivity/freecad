Where Are FreeCAD Macros Saved by Default?

In FreeCAD, recorded macros are stored locally on your computer inside dedicated user-profile directories tailored to your specific operating system. This article covers the default file system paths used by FreeCAD for Windows, macOS, and Linux, as well as the quick built-in methods to view or change this storage directory directly within the software.

Default File Paths by Operating System

FreeCAD automatically saves recorded .FCMacro scripts to the following default locations depending on your OS:

  • Windows:
    C:\Users\<username>\AppData\Roaming\FreeCAD\Macro\
    (You can access this quickly by pressing Win + R, typing %APPDATA%\FreeCAD\Macro, and pressing Enter.)

  • Linux:
    ~/.local/share/FreeCAD/Macro/
    (On older versions of FreeCAD, the path may be ~/.FreeCAD/Macro/ instead. Note that folders starting with a dot are hidden by default.)

  • macOS:
    /Users/<username>/Library/Application Support/FreeCAD/Macro/
    (In Finder, access this by choosing Go > Go to Folder... and pasting ~/Library/Application Support/FreeCAD/Macro/.)

How to Check the Macro Path Inside FreeCAD

If you are unsure where your files are going, you can verify the exact active path inside the FreeCAD interface:

  1. Open FreeCAD.
  2. Click Macro in the top menu bar.
  3. Select Macros... (or press the macro shortcut icon).
  4. Look at the bottom of the dialog window. The field labeled Macro destination displays the exact folder FreeCAD is currently reading from and saving to.

Changing the Default Macro Location

To redirect where FreeCAD records and searches for macros:

  1. Navigate to Edit > Preferences.
  2. Select the Python section on the left sidebar.
  3. Switch to the Macro tab.
  4. Under Macro recording settings, locate the Macro path input field.
  5. Click the browse button (...) to select any custom folder on your system.
  6. Click Apply and OK.
