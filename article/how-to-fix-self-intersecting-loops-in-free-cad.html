How to Fix Self-Intersecting Loops in FreeCAD

A self-intersecting loop occurs in FreeCAD when lines, arcs, or curves within a single sketch cross over themselves or share identical paths, preventing tools like Pad or Revolve from creating a solid body. This guide explains how to identify, locate, and repair these intersections using FreeCAD’s built-in validation tools and manual repair techniques, ensuring your sketches form clean, valid, closed profiles.

Use the "Validate Sketch" Tool

The fastest way to locate overlapping or crossing geometry is by using FreeCAD’s native diagnostic utility:

  1. Close your sketch if it is currently open.
  2. Ensure you are in the Sketcher Workbench or Part Design Workbench.
  3. Select the problematic sketch in the tree view.
  4. Go to the top menu and select Sketch > Validate sketch....
  5. Under the Self-intersection section, click Detect.

FreeCAD will highlight any points or segments where geometry crosses itself with a yellow or pink marker, directing you immediately to the problem area.

Common Causes and How to Repair Them

1. Overlapping or Crossing Edges

A loop must be a continuous, non-branching boundary. If two lines form an "X" or a figure-eight pattern:

  • Open the sketch for editing.
  • Select the Trim edge tool (shortcut: W).
  • Click the intersecting segments to remove the excess segments, or delete one of the crossing lines entirely.
  • Redraw the boundary so the path forms two distinct loops or a single perimeter that does not cross over itself.

2. Duplicate or Coincident Segments

Sometimes two lines are drawn directly on top of each other, making the overlap invisible at a glance:

  • In the Validate sketch dialog, use the Reversed points or Highlight missing coincidences checks.
  • In the sketch editor, box-select suspicious areas and check the Elements panel on the left. If a single visually apparent segment contains multiple IDs, select and delete the duplicate.

3. Internal Geometry Not Set to Construction Mode

Lines used purely for alignment, centering, or measurement inside a profile can register as intersecting edges:

  • Select any interior reference line, circle, or arc.
  • Toggle it to a construction element by clicking the Toggle construction geometry icon in the toolbar or pressing G then N.
  • Construction geometry turns blue and will not be calculated as part of the solid profile.

4. Shared Vertices Creating Multiple Loops

If two closed shapes share a single vertex (touching corners like an hourglass), FreeCAD cannot determine the volume:

  • Separate the shapes so that a small gap exists between them, or
  • Merge them into a single continuous outline using the Trim edge tool to remove the common touching point.

Verifying the Fix

Once modifications are complete, close the sketch editor and run Sketch > Validate sketch... once more. When the detection tool returns no self-intersections and reports that all endpoints are properly coincident, the sketch is fully prepared for 3D operations.
