Working Planes in FreeCAD Draft Workbench

In FreeCAD's Draft workbench, working planes are virtual two-dimensional surfaces placed within the three-dimensional environment to define where new geometric elements are drawn and manipulated. This article explains what working planes are, why they are essential for 2D drafting in a 3D CAD space, how to switch and align them to standard views or custom geometry, and how they interact with FreeCAD's snapping and coordinate systems.

What is a Working Plane?

A working plane is a dynamic reference frame that establishes a local 2D coordinate system—with its own X and Y axes—anywhere inside the 3D modeling space. When using drafting tools such as lines, wires, rectangles, or circles, the geometry needs an orientation to define its flat plane. The working plane serves as this drawing canvas, ensuring that clicks in the 3D view are translated accurately onto a designated 2D orientation rather than floating ambiguously in 3D space.

How Working Planes Function

When a Draft tool is active, FreeCAD projects user input directly onto the active working plane. Even if the camera view is rotated at an arbitrary angle, standard mouse clicks will snap to this virtual surface unless explicitly snapping to an off-plane object vertex.

The active working plane is controlled via the Working Plane button located in the Draft tray (or the Draft toolbar). It dictates:

  • Drawing Coordinates: The coordinates shown in the numerical input fields (X, Y, Z) correspond to the active plane's local coordinate system.
  • Snapping Projection: If the "Snap to working plane" option is enabled, geometry snapped to existing points outside the plane will project flat onto the working plane.
  • Grid Placement: The visual drafting grid aligns directly with the currently active working plane, providing a visual cue for orientation and scale.

Working Plane Modes and Alignment

The Draft workbench provides several ways to define the working plane:

  • Auto: Automatically adjusts the plane based on user interactions. If you look straight at a standard view (Top, Front, Side), the plane aligns to that view. If you select a planar face before activating a tool, the plane snaps to that face.
  • Standard Orthographic Planes (Top, Front, Side): Locks the drawing surface to global planes: Top (XY), Front (XZ), or Side (YZ).
  • Align to Selection: Positions the working plane directly on a selected planar face of an existing 3D solid or mesh. The origin and orientation of the plane match the normal vector and edges of the selected face.
  • Align to View: Sets the working plane perpendicular to the current camera angle, using the screen's center as the coordinate origin.
  • Three Points: Defines a custom plane by picking three points in space: the first sets the origin, the second defines the X-axis, and the third defines the direction of the Y-axis.

Working Plane Proxies

For complex projects requiring frequent shifts between custom angles, FreeCAD provides the Draft Working Plane Proxy. This tool saves the current position, orientation, and camera state of an active working plane as an object in the model tree. Clicking a proxy instantly restores its saved plane and alignment, eliminating the need to repeatedly reselect faces or reference points.
