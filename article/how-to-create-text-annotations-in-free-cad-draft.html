How to Create Text Annotations in FreeCAD Draft

This guide explains how to create, place, and customize 2D and 3D text annotations using the Draft Workbench in FreeCAD. You will learn the exact steps to insert standard text, attach leader lines using the Label tool, and adjust typography and formatting properties to ensure your technical drawings and 3D models are clearly documented.

Step 1: Switch to the Draft Workbench and Set the Working Plane

  1. Open your project in FreeCAD.
  2. In the workbench dropdown menu at the top of the interface, select Draft.
  3. Set your active Working Plane (found in the Draft tray at the bottom or top toolbar, depending on your UI layout). Choose Top (XY), Front (XZ), Side (YZ), or align it to a selected face. Text annotations are placed relative to this plane.

Step 2: Insert a Standard Text Annotation

  1. Click the Text tool icon in the toolbar, or go to the top menu and select Draft → Annotation → Text.
  2. Click in the 3D view to define the insertion point (base point) for your text.
  3. In the Task panel on the left, type the text you want to display. You can enter multiple lines by pressing Enter.
  4. Click Enter or the OK button in the Task panel to finalize the placement.

Step 3: Insert a Text Label with a Leader Line

If you need your annotation to point to a specific edge, vertex, or surface:

  1. Select the Label tool from the toolbar, or navigate to Draft → Annotation → Label.
  2. Click on the target point in the 3D view where the pointer/arrowhead should attach.
  3. Click a second point to define the position of the leader line's elbow or end.
  4. Click a third point to place the text block.
  5. In the Task panel, enter your annotation text and confirm.

Step 4: Edit Text Content and Position

  1. Select the created Text or Label object in the Tree View.
  2. Switch to the Data tab in the Property panel below the Tree View:
    • Text: Change the displayed message by editing the string list.
    • Placement: Adjust coordinates (X, Y, Z) and rotation angles.
    • Target Point (Labels only): Move the position of the arrow pointer.

Step 5: Adjust Font, Size, and Styling

  1. Select the text object in the Tree View.
  2. Switch to the View tab in the Property panel:
    • Font Size: Increase or decrease the text height to match your drawing scale.
    • Font Name: Enter the path or name of an installed TrueType/OpenType font file if a specific typeface is required.
    • Text Color: Set the color of the text characters.
    • Line Color (Labels only): Set the color of the leader line and arrow.
    • Line Spacing: Modify the distance between lines for multi-line notes.
