How to Export FreeCAD Tool Libraries for Reuse

This guide explains how to export, locate, and transfer tool libraries created in FreeCAD's CAM (formerly Path) Workbench so they can be reused across different projects or migrated to other machines. By leveraging FreeCAD’s ToolBit architecture, you can bundle your cutting tools, shapes, and library definitions into portable files, eliminating the need to redefine tool dimensions and feed rates for every new machining job.

Understanding FreeCAD's ToolBit System

Modern versions of FreeCAD manage cutting tools through the ToolBit system, which organizes tool data into three interdependent components:

  • ToolBits (.fctb): Individual tool configurations defining parameters like diameter, cutting edge height, and material.
  • Shapes (.fcstd): 3D profile models representing the geometric archetype of a tool (e.g., endmill, ball end, V-bit).
  • Tool Libraries (.fctl): Plain-text JSON files that compile collections of .fctb tools into categorized working sets.

To successfully reuse or export a library, you must share both the .fctl library file and its referenced .fctb tool bit files.

Method 1: Exporting via the File System

The most reliable way to export complete tool libraries for use across projects or systems is to copy them directly from FreeCAD's application directory.

  1. Locate your FreeCAD CAM directory:
    • Windows: %APPDATA%\FreeCAD\CAM\ (or %APPDATA%\FreeCAD\Path\)
    • Linux: ~/.local/share/FreeCAD/CAM/ or ~/.FreeCAD/CAM/
    • macOS: ~/Library/Application Support/FreeCAD/CAM/
  2. Select the necessary folders: Inside the directory, locate the following subfolders:
    • Library/: Contains your .fctl library definition files.
    • Tool/: Contains the individual .fctb tool files.
    • Shape/: Contains any custom shape templates you generated.
  3. Copy and package the files: Copy your desired .fctl files from the Library/ folder along with all corresponding .fctb files from the Tool/ folder to your backup location or target machine.

Method 2: Exporting from the ToolBit Library Manager

You can manage and export libraries directly from the FreeCAD graphical interface:

  1. Open FreeCAD and switch to the CAM (or Path) workbench.
  2. Navigate to the top menu and select CAM > ToolBit Library Manager (or click the tool manager icon on the toolbar).
  3. In the manager window, select the library you want to export from the library dropdown.
  4. Click the Save Library As or folder icon to export the .fctl file to a custom directory on your system, such as a shared network drive or project folder.
  5. Ensure any individual tools created specifically for this library are also saved using the Save ToolBit As option to make them accessible outside default locations.

Importing and Reusing the Library in a New Project

Once your library files are exported, use them in any new project using the following steps:

  1. Create or open your target FreeCAD document and create a new CAM Job.
  2. Open the ToolBit Library Manager.
  3. Click the Open Library button and browse to the location of your exported .fctl file.
  4. If working on a different computer, paste the exported .fctb files into the local machine's CAM/Tool/ folder so FreeCAD can resolve the tool paths.
  5. Select the required tools from the loaded library and click Add to Job to assign tool controllers to your active operations.
