How to Contribute FreeCAD Translations

Contributing translations to FreeCAD is a straightforward process managed through Crowdin, a collaborative localization platform. This guide explains how to set up an account, join the FreeCAD localization project, translate interface strings and documentation, follow key formatting rules, and see your work integrated into upcoming software releases.

1. Create an Account on Crowdin

FreeCAD manages its official localization through the Crowdin platform. To start:

  1. Visit Crowdin (crowdin.com) and create a free account if you do not already have one.
  2. Verify your email address and complete your profile setup.

2. Join the FreeCAD Project

Once registered:

  1. Navigate to the official FreeCAD project page on Crowdin (search for "FreeCAD" in the Crowdin search bar or access the project directly).
  2. Click the Join button to request access or join the translation team.
  3. Select your target language from the list of available languages. If your native language is not listed, you can request its addition through the FreeCAD forum or the Crowdin project discussions.

3. Select Files to Translate

Inside your chosen language, you will see various components of FreeCAD:

  • FreeCAD Core: Contains strings for the main user interface, workbenches, and standard tools.
  • Addons and Workbenches: Contains strings for external or modular workbenches.
  • Documentation/Website: Covers the project website and user documentation where applicable.

Click on a file to open Crowdin's translation editor.

4. Translate Strings in the Crowdin Editor

The Crowdin editor displays the original English text on the left and input fields for your translation on the right:

  • Translate Untranslated Strings: Filter the file by "Untranslated" to locate strings needing conversion.
  • Vote on Existing Translations: If an entry already has multiple suggestions, vote for the most accurate one or submit a better alternative.
  • Review Context: Check the contextual notes, screenshots, or code references provided in the editor to ensure your translation fits the intended technical meaning.

5. Follow Translation and Formatting Rules

To avoid software bugs and broken interfaces, adhere strictly to these rules:

  • Preserve Variables and Placeholders: Do not translate formatting tags or code placeholders such as %1, %s, {0}, or HTML tags like <b> and </b>. Keep them in the exact form required by the application.
  • Maintain Keyboard Shortcuts: Strings containing an ampersand (&) indicate keyboard shortcuts (e.g., &File). Place the ampersand before the corresponding letter in your language if possible.
  • Use Consistent Terminology: Refer to established CAD terminology in your language. Consult the FreeCAD glossary feature within Crowdin to maintain consistency across workbenches.

6. Integration and Testing

  • Approval: Proofreaders and language managers regularly review and approve submitted strings.
  • Export and Releases: Approved translations are automatically pulled into the FreeCAD source code repository periodically. They will appear in the weekly development builds and subsequent official stable releases.
  • Testing in FreeCAD: To test your work locally, download a recent FreeCAD development build, navigate to Edit > Preferences > General, and change the language setting to your target language.
