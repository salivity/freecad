How to Enable Dark Theme in FreeCAD

This guide explains how to configure FreeCAD to use a dark theme to reduce eye strain and modernize the interface. You will learn how to apply the built-in dark stylesheets for the user interface, adjust the 3D viewport canvas background to match, and install custom community themes using the FreeCAD Addon Manager.

Step 1: Change the Interface Style Sheet

FreeCAD includes pre-installed dark stylesheets that change the color of menus, toolbars, and panels.

  1. Open FreeCAD.
  2. Navigate to Edit > Preferences from the top menu bar (on macOS, go to FreeCAD > Preferences).
  3. Select the General section from the left sidebar, and remain on the General tab.
  4. Locate the Style sheet dropdown menu.
  5. Choose one of the available dark themes:
    • OpenDark: A balanced dark theme with high contrast.
    • ProDark: A darker, professional-style palette.
    • Dark modern: Available in recent versions, providing a sleek, modern UI.
  6. Click Apply, then OK. The interface will update immediately.

Step 2: Set a Dark 3D Viewport Background

Changing the style sheet only affects menus and toolbars. To make the 3D modeling space dark:

  1. Open Edit > Preferences.
  2. Select Display from the left sidebar and click on the Colors tab.
  3. In the Background section, locate the color settings:
    • For a uniform background, set the mode to Simple color and choose a dark gray or black.
    • For a gradient background, choose Linear gradient or Radial gradient, then set both the top and bottom colors to dark tones.
  4. Click Apply and OK to save the changes.

Step 3: Install Additional Community Themes (Optional)

If the default dark themes do not suit your workflow, additional themes are available through the Addon Manager:

  1. Go to Tools > Addon Manager.
  2. Select the Preference Packs tab.
  3. Browse the list for dark community themes (such as FreeCAD Dark, OLED Dark, or Gruvbox).
  4. Select the desired pack and click Install.
  5. Once installed, apply the new theme via Edit > Preferences > General > Style sheet, or activate it through the Preference Packs manager.
  6. Restart FreeCAD to ensure all graphical elements render correctly.
