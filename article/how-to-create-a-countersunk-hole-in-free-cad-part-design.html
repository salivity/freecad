How to Create a Countersunk Hole in FreeCAD Part Design

Creating a countersunk hole in FreeCAD Part Design is easily accomplished using the built-in Hole feature rather than manually revolving a cut. This guide covers the entire workflow, from placing the hole center using a sketch point to setting the countersink angle, diameter, and depth parameters to fit standard fasteners.

Step 1: Define the Hole Location

  1. Open your model in the Part Design workbench.
  2. Select the planar face where you want to place the countersunk hole.
  3. Click Create a new sketch (or attach a sketch to the selected face).
  4. Select the Create a point tool from the sketcher toolbar and place a point where the center of the hole should be located.
  5. Apply dimensional constraints to position the point accurately on the face.
  6. Click Close to exit the sketcher.

Step 2: Open the Hole Tool

  1. Ensure the sketch containing your point is selected in the tree view.
  2. Click the Hole icon in the Part Design toolbar (or go to Part Design > Create a substractive feature > Hole).
  3. The model will display a preview of a basic hole, and the Hole parameters panel will appear in the Tasks tab on the left.

Step 3: Configure Countersink Parameters

In the Tasks panel, adjust the following settings to create the countersink:

  • Hole Cut Type: Click the dropdown menu currently set to "Regular" and change it to Countersunk.
  • Countersink Diameter: Enter the outer diameter of the conical depression to match your screw head.
  • Countersink Angle: Set the angle of the conical cut. Standard metric flat-head screws typically use 90°, while imperial/inch fasteners often use 82°.
  • Diameter: Set the clearance or pilot diameter for the screw shank.
  • Depth: Choose the termination condition for the through-hole:
    • Select Through all if the hole should pass entirely through the body.
    • Select Dimension if you need a blind hole, and specify the depth value.

Step 4: Finalize the Feature

Review the 3D viewport to ensure the preview matches your design requirements. Click OK at the top of the Tasks panel to complete the countersunk hole. The new feature will appear in your model tree as a "Hole" object, which you can double-click at any time to modify the dimensions.
