How to Create Exploded Views in FreeCAD

Creating an exploded view of an assembly model in FreeCAD is essential for technical drawings, assembly instructions, and presentations. This guide walks you through the process of installing the dedicated ExplodedAssembly workbench, selecting parts, defining separation trajectories, and fine-tuning movement distances to clearly showcase individual components.

1. Install the ExplodedAssembly Workbench

While FreeCAD has multiple assembly workbenches, the ExplodedAssembly add-on is the most dedicated and efficient tool for creating exploded views and animations.

  1. Open FreeCAD.
  2. Navigate to the top menu and select Tools > Addon Manager.
  3. Under the Workbenches tab, search for ExplodedAssembly.
  4. Select it and click Install.
  5. Restart FreeCAD once the installation finishes.

2. Prepare the Assembly

Before exploding your model, ensure the assembly is properly structured:

  1. Open your assembly file in FreeCAD.
  2. Switch to the ExplodedAssembly workbench using the workbench dropdown selector.
  3. Ensure all parts are individual solids or grouped objects within the model tree so they can be moved independently.

3. Create Explosions (Disassemble Parts)

Exploding parts involves defining a trajectory and distance along a specific axis or edge.

  1. Select the component: In the 3D view or the tree view, click on the part you wish to move away from the main assembly.
  2. Define the direction:
    • Select a linear edge, face normal, or axis on the model that aligns with the direction you want the part to travel.
    • Hold Ctrl (or Cmd on macOS) while selecting both the part and the reference edge.
  3. Disassemble the part: Click the Create a bolt exploded-track or Disassemble part tool from the workbench toolbar.
  4. The part will move along the chosen vector, creating an explosion track object in the tree view.

4. Adjust Distance and Placement

If a part travels in the wrong direction or the displacement is too small:

  1. Select the generated trajectory or exploded step in the Tree view.
  2. Go to the Data tab in the Property panel below the tree view.
  3. Modify the Distance property to increase or decrease the offset.
  4. Set the Reverse property to True if the part moved in the opposite direction of what was intended.

5. Add Trajectory Lines

Visual explosion lines help indicate where parts belong in the final assembly:

  1. Select the exploded track object in the Tree view.
  2. In the Property panel, adjust the visibility settings to display centerlines or motion paths between the disassembled component and its origin.

6. Export to TechDraw for 2D Drawings

Once the 3D model is exploded satisfactorily:

  1. Switch to the TechDraw workbench.
  2. Insert a new standard drawing page.
  3. Position your 3D view to the desired angle in the viewport.
  4. Select the assembly in the tree view and click Insert View in the TechDraw workbench to generate an isometric technical drawing of your exploded assembly.
